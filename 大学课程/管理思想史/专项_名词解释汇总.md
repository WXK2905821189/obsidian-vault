# 📖 名词解释专项训练 — 管理思想史（第7章 & 第8章）

> **考试范围**：第7章全部 + 第8章（知识管理/创新/跨文化/组织理论）
> **使用方法**：先自己口头解释，再对照「一句话定义」检查，用自己的话复述一遍。

## 第7章

|  #  | 名词       | 一句话定义                                                |
| :-: | -------- | ---------------------------------------------------- |
|  1  | 组织文化（沙因） | 群体在处理外部适应与内部聚合中发展出的共享假设和价值观，传授给新成员作为正确认知方式           |
|  2  | 睡莲模型     | 沙因提出的文化三层结构：人工制品(表)→价值观(中)→基本假设(深)                   |
|  3  | Z理论      | 大内提出：融合日本终身雇佣/集体决策与美国效率优势的Z型组织模式                     |
|  4  | 7S模型     | 帕斯卡尔提出：战略/结构/制度(硬3)+人员/风格/技能/共同价值观(软4，核心)            |
|  5  | 权力距离(PD) | 霍夫斯泰德维度：社会对权力分配不平等的接受程度                              |
|  6  | PDCA循环   | 戴明提出：Plan→Do→Check→Act，质量持续改进循环                      |
|  7  | 二八法则     | 朱兰提出：80%的质量问题由20%的原因引起                               |
|  8  | 第三次浪潮    | 托夫勒1980年著作，指信息技术/知识经济引发的社会变革                         |
|  9  | OLI范式    | 邓宁提出：所有权优势(O)+区位优势(L)+内部化优势(I)，解释境外直接投资              |
| 10  | 双环学习     | 阿吉里斯提出：不仅改变行为，还改变行为背后的假设和价值观                         |
| 11  | 组织防卫     | 阿吉里斯提出：组织面对威胁时的自保性反应，阻断深层探究                          |
| 12  | 三叶草组织    | 汉迪提出：由核心员工/外包/临时工三种人员组成的组织形态                         |
| 13  | 坎特法则     | 尊重员工是人性化管理的必然要求，回报率最高的感情投资                           |
| 14  | 五力模型     | 波特提出：新进入者/替代品/买方/供方/现有竞争者五种力量分析行业竞争强度                |
| 15  | 战略3C     | 大前研一提出：公司(Corporation)+顾客(Customer)+竞争者(Competition) |
| 16  | 活力曲线     | 韦尔奇工具：按绩效分20%优秀/70%中等/10%淘汰                          |
| 17  | 自来水哲学    | 松下幸之助：让产品像自来水一样便宜充足，造福大众                             |

## 🎯 名词解释模拟练习

**自测方法**：看名词→闭卷写80-120字→对照评分要点。

**1. 组织文化（沙因）**：人物✓ 共享假设价值观✓ 传授新成员✓ 睡莲模型三层✓ 意义✓

**2. SECI模型**：人物✓ 隐性/显性区分✓ 四种转化(S/E/C/I)✓ 外化最关键✓ 隐性>显性✓

**3. 颠覆性创新**：人物✓ 低端切入✓ 最终颠覆✓ 大公司盲区✓ 五项应对原则✓

**4. 五项修炼**：人物✓ 五修名称✓ 系统思考是核心✓ 整合作用✓ 突破学习障碍✓

**5. Z理论**：人物✓ 日美对比背景✓ 七维对比(列2-3)✓ Z型组织主张✓

**6. 五力模型**：人物✓ 五种力量✓ 分析行业竞争强度✓ 与三战略匹配✓

**7. 智力资本**：人物✓ 无形资产总称✓ 四分类✓ 评估意义✓

**8. 双环学习**：人物✓ 改变行为+假设✓ vs单环学习✓ 学习型组织奠基人✓

**9. HR四角色**：人物✓ 四种角色名称✓ 每角色产出✓ 领导者=四角色总和✓

**10. 科特八步法**：人物✓ 八步顺序✓ 组织变革✓ 每步有常见错误✓

## ⚡ 背题速过

1. 睡莲模型 → 沙因/三层/表·中·深
2. Z理论 → 大内/日美对比/终身·集体·非专业
3. PDCA → 戴明/计划·执行·检查·处理
4. 五力 → 波特/新进入者·替代品·买方·供方·竞争者
5. 双环学习 → 阿吉里斯/改行为+改假设
6. SECI → 野中/S·E·C·I/隐性>显性
7. 五项修炼 → 圣吉/自我超越·心智模式·愿景·团队·系统(核心)
8. 颠覆性创新 → 克里斯坦森/低端入手/最终颠覆
9. HR四角色 → 尤里奇/战略伙伴·行政专家·激励者·变革推动者
10. 智力资本 → 布鲁金/四类：市场·知识产权·人才·基础结构
