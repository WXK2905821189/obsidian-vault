# 第4章 供应链综合计划 —— 知识点总结

> 依据：第4章PPT | 含全部知识点

---

## 一、综合计划概述

### 1.1 什么是综合计划

综合计划（Aggregate Planning）是在**3-18个月**的时间范围内，对生产、库存、劳动力等资源进行整体规划，以**利润最大化**为目标。

### 1.2 综合计划要回答的问题

| 决策维度 | 具体问题 |
|---------|---------|
| **生产速率** | 每月/每季度生产多少？ |
| **劳动力** | 雇佣多少人？加班还是裁员？ |
| **库存** | 建立多少库存来应对需求高峰？ |
| **转包** | 产能不足时转包多少给外部？ |
| **缺货/延迟交货** | 允许缺货吗？允许多久？ |

---

## 二、综合计划的权衡

### 2.1 基本权衡关系

| 权衡        | 选项一                    | 选项二               |
| --------- | ---------------------- | ----------------- |
| **产能策略**  | 按需求高峰建产能（产品可得性好，产能闲置多） | 按平均需求建产能（旺季缺货/转包） |
| **劳动力策略** | 按需求调整劳动力（加班、临时工、裁员）    | 稳定劳动力（库存缓冲）       |
| **库存策略**  | 旺季前建立库存（库存成本高）         | 旺季加班生产（劳动力成本高）    |
| **缺货策略**  | 允许延迟交货（损失顾客信任）         | 建更多产能/库存（成本高）     |

### 2.2 关键成本项

| 成本类型 | 内容 |
|---------|------|
| 生产成本 | 原材料、直接人工 |
| 劳动力调整成本 | 雇佣/解雇/培训成本 |
| 加班成本 | 高于正常工资的部分 |
| 库存持有成本 | 资金占压、仓储 |
| 缺货/延迟交货成本 | 顾客流失、信誉损失 |
| 转包成本 | 外部生产成本（通常高于自制） |

---

## 三、综合计划策略

### 3.1 追逐策略（Chase Strategy）

- 按需求变化调整生产速率
- 劳动力随需求而变
- 优点：库存成本低
- 缺点：劳动力调整成本高

### 3.2 平稳策略（Level Strategy）

- 保持稳定的生产速率
- 通过库存缓冲需求波动
- 优点：劳动力稳定
- 缺点：库存成本高

### 3.3 混合策略

- 综合使用多种手段：库存缓冲、加班、转包、延迟交货
- 实际企业通常采用混合策略

---

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 综合计划 | 3-18个月中期规划，利润最大化 |
| 决策维度 | 生产速率、劳动力、库存、转包、缺货 |
| 三种策略 | 追逐（调产能）、平稳（库存缓冲）、混合 |
| 核心权衡 | 劳动力调整成本 vs 库存持有成本 |
