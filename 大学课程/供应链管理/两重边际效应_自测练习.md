## 一、核心概念题（填空题，每空2分，共10分）

1. 两重边际效应（Double Marginalization）是指：供应链中制造商和零售商各自独立加价，导致最终零售价________于供应链整体最优价格，总销量________于最优水平，供应链总利润________。

2. PPT中提到的解决两重边际效应的一种企业间契约是________合同，即供应商承诺以一定价格回购零售商未售出的商品。

3. 回购合同适用于________品（如报纸、面包、时装），因为零售商担心过期/过季而不愿多进货。

# 📝 参考答案

## 第二部分：两重边际效应

### 一、核心概念题

1. **高**、**低**、**减少**（低于一体化最优）
2. **回购**（buyback）
3. **易逝**品

### 二、判断题

| 题号 | 判断 | 解析 |
|------|------|------|
| 1 | ❌ | 三层以上同样存在，且层层加价效应会累积放大 |
| 2 | ✅ | PPT第18页："在适当的批发价格和回购价格下，双方都会增加利润" |
| 3 | ✅ | 担心卖不掉→少进货→但这样也会损失可能的销售机会 |
| 4 | ✅ | 回购 = 制造商说"卖不掉我帮你兜底"→零售商更敢进货 |
| 5 | ✅ | b=w时，零售商零风险（卖不掉全退），但制造商承担全部过剩成本 |

### 三、计算与推理题

**1. 报纸回购合同计算**

**(a) 无回购合同**

报摊面临报童模型：
- 缺货成本(underage)：Cu = p - w = 10 - 5 = 5（少卖一份损失5元利润）
- 过剩成本(overage)：Co = w - 0 = 5（多进一份浪费5元成本）
- 临界分位点：CSL = Cu/(Cu+Co) = 5/(5+5) = 0.5

需求分布：50(0.5) 或 150(0.5)，CSL=0.5 → 订货量 = 50 份

报摊期望利润：
- 若需求50：利润 = 50×(10-5) = 250
- 若需求150：利润 = 50×5 = 250（缺货，但只进了50份）
- 期望利润 = 250

出版商利润（无回购）：
- 若需求50：50×(5-2) = 150
- 若需求150：50×3 = 150
- 期望利润 = 150

供应链总利润 = 250 + 150 = 400

**(b) 有回购合同 b=3**

报摊新的成本结构：
- 缺货成本：Cu = 10 - 5 = 5（不变）
- 过剩成本：Co = 5 - 3 = 2（未售出可以3元退回，实际损失只有2元/份）
- CSL = 5/(5+2) = 5/7 ≈ 0.71 > 0.5 → 订货量增加到 **150 份**

报摊期望利润：
- 若需求50：收入=50×10+100×3=800，成本=150×5=750，利润=50
- 若需求150：收入=150×10=1500，成本=150×5=750，利润=750
- 期望利润 = 0.5×50 + 0.5×750 = **400**（提高了！）

出版商期望利润：
- 若需求50：批发收入=150×5=750，回购支出=100×3=300，生产成本=150×2=300，利润=750-300-300=150
- 若需求150：批发收入=150×5=750，回购支出=0，生产成本=150×2=300，利润=450
- 期望利润 = 0.5×150 + 0.5×450 = **300**（也提高了！）

供应链总利润 = 400 + 300 = **700** > 400 ✅

> 结论：回购合同让报摊从订50份增加到150份，双方利润都增加，供应链总利润从400升到700。

---

**2. 回购价格提高的影响分析**

**(a) 订货量变化**：随回购价提高，订货量**单调递增**。因为Co = w-b 越来越小，零售商过剩风险越来越小。

**(b) 品牌方利润变化**：呈**倒U形**——回购价过低则零售商不敢多订货，总销量少；回购价过高则制造商承担过多过剩风险。存在最优回购价。

**(c) 供应链总利润**：在适当范围内随回购价上升而增加，超过某点后由于过度订货导致大量过剩而下降。

**(d) 不是越高越好**。b=w时零售商零风险，会无限订货，反而不经济。最优回购价使供应链总利润最大化但小于批发价。

### 四、概念对比题

| 对比维度 | 回购合同 | 数量折扣 |
|---------|---------|---------|
| 解决的核心问题 | 零售商**怕卖不掉**（需求不确定→不敢多进） | 零售商**逐批加价**（每次只按自己利润最大化订货→批量偏小） |
| 风险由谁承担 | 制造商分担过剩风险（回购未售品） | 风险仍在零售商，但降低了边际成本 |
| 适用产品类型 | 易逝品、季节性商品、时尚品 | 任何产品，但常用在需求较稳定的场景 |
| 对订货量的影响 | 降低过剩成本Co → 提高CSL → 增加订货量 | 降低单位采购成本 → EOQ可能变化 → 促进大批量采购 |
| 对总利润的影响 | 风险分担 → 减少双重加价 → 总利润增加 | 降低采购成本 → 总利润可能增加（需防止牛鞭效应） |

### 五、综合应用题要点

**1. 问题诊断**

| 问题 | 相关效应 |
|------|---------|
| 夏天断货 → 便利店"不敢多进" | **两重边际效应**：便利店只考虑自身利润最大化，怕剩货而少进，导致缺货损失 |
| 秋天不敢进 → 同样原因 | **两重边际效应** |
| 订货量忽高忽低 | **牛鞭效应**：便利店根据自身库存和季节判断订货，波动被放大到品牌方 |

两重边际效应导致订货量**系统性偏低**，牛鞭效应导致订货量**波动大**，两者叠加→生产计划无法制定。

**2. 回购合同设计**

建议：批发价 w=8 不变，回购价 b=5（高于生产成本3，低于批发价8）

- 便利店：Co = 8-5 = 3 ↓（比原来8的损失小很多），更敢多进货
- 品牌方：承担部分过剩风险，但总销量↑，综合利润可能↑
- 具体最优b需要根据需求分布精算，但大致应在成本(3)和批发价(8)之间

**3. 配合其他协调手段**

| 手段 | 措施 |
|------|------|
| **信息共享** | 品牌方获取便利店POS数据，了解每日真实销量，做出更好的生产预测 |
| **目标一致性的激励** | 回购合同本身+将便利店的"销售预测准确率"纳入合作考核 |
| **改进运作模式** | 缩短生产提前期，建立小批量补货机制，减少便利店囤货需求 |
| **建立信任承诺** | 从单次回购合同升级为长期框架协议，降低双方博弈成本 |

---

> 📌 **两重边际效应速记**：各自加价→价高量少→总利下降。破解：回购合同（分担过剩风险）、收益共享（变固定批发为分成）。
>
> 📌 **分销网络速记**：设施↑→响应↑库存↑运输先↓后↑→总成本倒U形。四种网络：制造商直送、分销商+包裹、在途并货、分销+到户。
