| 采购批量Q（斤） | 单价P（元/斤） |
|:------------:|:------------:|
| Q < 20000 | 1.20 |
| 20000 ≤ Q < 40000 | 1.10 |

### 案例一：服装品牌的供应链困境（15分）

某快时尚服装品牌Z采用以下供应链模式：
- 设计团队每年推出2000款新品
- 生产外包给东南亚合同制造商
- 通过全国300家直营门店销售
- 补货方式：各门店店长每周凭经验下单，区域仓汇总后发给制造商

- 爆款常常断货（补货周期长达6周）

- 财务总监发现：缺货损失 + 季末打折损失 = 年销售额的15%

**问题**：
(a) 案例中出现了PPT中的哪几类供应链失调障碍？请逐一指出并说明具体表现。（6分）
(b) Z公司目前的补货模式属于哪类补货政策？如果改为另一种补货政策，订货量将如何变化？（3分）

## 📝 参考答案

### 一、简答题

**1. 战略匹配**

战略匹配是指：供应链的性能表现（响应-效率组合）要匹配目标市场的**隐含不确定性**。

| 服装类型 | 隐含不确定性 | 匹配的供应链 |
|---------|:----------:|:----------:|
| 时尚女装 | **高**（款式年年变、需求难预测、交货要快） | **响应型**供应链（柔性生产、快速补货） |
| 职场服装 | **中**（款式每年有变化、需求可预测） | 居中策略 |
| 劳保服装 | **低**（款式长期不变、需求量稳定） | **效率型**供应链（大规模生产、低成本） |

> PPT第1章：隐含不确定性越高 → 越需要响应性；越低 → 越追求效率性。

---

**2. 牛鞭效应与四类障碍**

牛鞭效应：需求信息从最终消费者向上游传递时，订单波动逐级放大的现象。

| 障碍 | 一句话说明 |
|------|-----------|
| **信息障碍** | 各环节仅根据下游订单预测需求，缺乏信息共享 |
| **错误激励** | 考核/契约引导了扩大波动的行为（如按sell in考核销售人员） |
| **运作错误（配给博弈）** | 短缺时按订单比例配给→下游故意虚增订单 |
| **错误的行为范式** | 缺乏系统思考，互不信任，只从身边找原因 |

---

**3. 库存集成效应**

库存集成效应：将多个分散仓库合并为一个集中仓库后，总安全库存下降的现象。

**原因**：不同区域的需求波动可以**互相抵消**——A区需求高时B区可能低。

**减少幅度**：受各区域需求**相关系数ρ**影响。
- ρ = 0（完全独立）：集中安全库存 = 分散总和的 1/√k
- ρ = 1（完全正相关）：集中 = 分散，无集成效果
- ρ越低，集成效果越显著

---

**4. 四种分销网络**

| | 响应时间 | 库存成本 |
|------|:------:|:------:|
| **制造商存货加直送** | **长**（从工厂发货，距离远） | **低**（集中存于制造商） |
| **分销商存货加包裹交付** | **短**（从就近分销商发货） | **高**（分散存于多个分销商） |

另外两种：制造商存货+在途并货（直送的变体，运输成本更低）、分销存货+到户交付（巡回配送）。

---

**5. 配给博弈**

**定义**：产品供不应求时，上游按订单比例配给→下游为获得更多配额而故意夸大订单。

**数字举例**（PPT第15页）：

| | 零售商A不虚增 | 零售商A虚增 |
|------|:----:|:----:|
| A订货量 | 50 | **90** |
| B订货量 | 50 | 50 |
| A配给量 | 50 | **60** |
| B配给量 | 50 | 40 |

A虚增订单→多拿10件→B吃亏→下次B也虚增→恶性循环。

**PPT方案**：基于下游**实际销售量**（而非订单量）来配给有限供给量。

### 二、计算题

**1. 数量折扣EOQ**

**(a) 各区间EOQ**

EOQ = √(2DS/H)，D=240000，S=100

| 价格P | H=0.2P | EOQ | 在区间？ | 可行Q |
|:----:|:------:|:---:|:------:|:----:|
| 1.20 | 0.24 | 14142 | ✅ (Q<20000) | 14142 |
| 1.10 | 0.22 | 14771 | ❌ (需Q≥20000) | **20000**（下限） |
| 1.00 | 0.20 | 15492 | ❌ (需Q≥40000) | **40000**（下限） |

**(b) 各方案总成本** TC = DP + (D/Q)S + (Q/2)H

| Q | P | 采购成本 | 订货成本 | 持有成本 | TC |
|:-----:|:---:|--------:|-------:|-------:|------:|
| 14142 | 1.20 | 288000 | 1697 | 1697 | **291394** |
| 20000 | 1.10 | 264000 | 1200 | 2200 | **267400** |
| 40000 | 1.00 | 240000 | 600 | 4000 | **244600** |

**(c) 最优解**：**Q* = 40000斤**，最低年总成本 **244600元**。

---

**2. 安全库存计算**

**(a) 提前期内需求标准差**

σ_L = σ_D × √L = 100 × √4 = 100 × 2 = **200件**

**(b) 安全库存（CSL=95%）**

ss = F⁻¹(CSL) × σ_L = 1.65 × 200 = **330件**

**(c) CSL提高到99%**

ss_99 = 2.33 × 200 = **466件**

增幅 = (466-330)/330 × 100% = **41.2%**

> CSL仅提高4个百分点，安全库存却增加41%——边际成本递增。

**(d) 提前期压缩到1周（CSL=95%）**

σ_L_new = 100 × √1 = 100
ss_new = 1.65 × 100 = **165件**

比例 = 165/330 = **50%**（安全库存减半）

> 压缩提前期是降低安全库存最有效的手段。

### 三、案例分析

**案例一：服装品牌Z**

**(a) 失调障碍分析**

| 障碍 | 具体表现 |
|------|---------|
| **信息障碍** | 制造商只看到汇总后的订单，不知道各门店实际销售和库存状况 |
| **错误激励** | 店长奖金与月度销售额挂钩→月底打折冲量→订单信号失真 |
| **运作错误** | 补货周期长达6周→店长为了不断货而多囤→放大需求信号到上游 |
| **错误的行为范式** | 店长"凭经验下单"不考虑对上游影响；制造商只抱怨订单波动 |

**(b) 补货政策**

目前：各门店**每周凭经验下单** → **周期盘点**（定期盘存），固定周期（1周），不固定订货量。

若改为**连续盘点**：设定订货点ROP，库存降到ROP时自动补货固定数量Q。订货量变为**固定值Q**，订货时机由库存驱动而非日历驱动。

**(c) 改进方案（对应四种手段）**

| 手段 | 措施 |
|------|------|
| **信息共享** | 所有门店的POS销售数据和库存数据实时共享给区域仓和制造商 |
| **目标一致性的激励** | 将店长考核从"月度销售额"改为"销售额+库存周转率"双指标，避免月末冲量 |
| **改进运作模式** | 缩短补货周期（如建立区域快速响应仓），改为小批量高频次补货 |
| **建立信任和承诺** | 与制造商签订长期框架协议+弹性产能条款（±30%可调），减少双方的博弈和囤货行为 |

**案例二：冷链生鲜物流网络**

**(a) 年总成本计算**

日总订单 = 8000+3000+2500+2000+1500 = 17000单/天

| 方案 | 固定成本 | 配送成本(年) | 年总成本 |
|:--:|:------:|------------:|:------:|
| A | 200万 | 17000×365×12 = 7446万 | **7646万** |
| B | 350万 | 17000×365×8 = 4964万 | **5314万** |
| C | 600万 | 17000×365×5 = 3102.5万 | **3702.5万** |

**(b) 方案C配送成本最低但总成本未必最优的原因**

- 配送成本低：仓库离顾客近，配送距离短
- 但固定成本高：建5个仓库
- **库存成本更高**：5个仓各备安全库存 → 丧失库存集成效应 → 总安全库存远大于1个仓
- 生鲜损耗成本更高：每个仓都要备货 → 分散库存 → 过期损耗↑
- 装卸成本更高：设施越多，装卸次数越多

> PPT第2章：总成本 = 设施成本 + 库存成本 + 运输成本 + 装卸成本，呈倒U形曲线。

**(c) 生鲜电商的权衡建议**

**少建仓（集中）的好处**：
- 库存集成效应 → 安全库存低 → 生鲜损耗少
- 固定设施成本低

**多建仓（分散）的好处**：
- 响应时间短（可实现当日达/次日达）
- 配送成本低

**综合建议**：
- 在核心城市（上海）建**区域中心仓**，覆盖200km半径（上海+苏州+部分杭州/宁波）
- 在次核心城市（杭州）建**卫星仓**，覆盖杭州+宁波
- 利用库存集成效应（2仓 vs 5仓）：安全库存约降低 1-√(2/5)≈37%
- 对于保质期极短的商品（如鲜奶、沙拉），可采用"制造商直送门店"或cross-dock模式，DC不持库存
- 配合第9章外包：将末端配送外包给即时物流平台（美团/蜂鸟），专注仓内运营

> 核心：生鲜不能像标品那样大量囤货 → 更应追求**库存集成** → 仓不宜太多，但要配合快速补货机制。
