# 第9章 供应链中的采购决策 —— 知识点总结

## 一、采购概述

### 1.1 采购的含义

| 术语               | 含义                             |
| ---------------- | ------------------------------ |
| 购买（Purchasing）   | 公司为自身生产运作，从供应商处购买原材料、零部件、服务的过程 |
| **采购（Sourcing）** | 包含但不限于购买，是一个更完整的管理过程           |

### 1.2 采购管理的五项内容

| 环节 | 内容 |
|------|------|
| ① 供应商评分和评估 | 根据业绩对潜在供应商打分、排队 |
| ② 供应商选择和合同谈判 | 确定供应商，洽谈合同条款 |
| ③ 设计协作 | 与供应商协作设计其供应的产品及生产工艺 |
| ④ 购买（Purchasing） | 下达订单，供应商生产并交付 |
| ⑤ 采购计划和分析 | 分析支出和效果，寻找改进机会 |

## 二、自制还是外包

### 2.1 决策框架

外包能增加供应链整体剩余，但也会带来风险。

```
外包决策 = 权衡（外包带来的利益）vs（外包带来的风险）
```

### 2.2 外包的七大集成效应（利益）

| 集成效应 | 含义 | 举例 |
|---------|------|------|
| **能力集成** | 分包商同时为多个买方供应，规模>单个买方 | Intel供芯片给Dell等多家PC厂 |
| **库存集成** | 统一经销→库存成本低于各自持有 | 日杂商品生产者不自己销售 |
| **3PL运输集成** | 第三方物流集成多托运人任务→成本更低 | 沃尔玛自建车队（需求量大，集成效果不显著） |
| **独立仓储商运输集成** | 独立仓储集成多个卖方→内外运输成本更低 | |
| **独立仓储商设施集成** | 一个仓储商服务多客户→设施成本更低 | |
| **采购/合同制造集成** | 一个采购商为多个小买方执行采购→成本更低 | 富士康(合同制造)、台积电 |
| **信息集成** | 信息集成商集中买卖信息→比分散搜寻成本低 | 阿里巴巴、淘宝 |

### 2.3 外包的风险

| 风险 | 说明 |
|------|------|
| 供应链失控 | 失去对关键环节的直接管理 |
| 信息泄露 | 商业机密、技术诀窍外泄 |
| 被架空 | 供应商掌握全链条后可能"去中间化" |
| 质量风险 | 供应商可能为降成本牺牲质量 |
| 协调成本 | 跨组织协调比内部协调更困难 |
| 创新能力下降 | 失去制造环节的学习效应 |

### 2.4 集成效应显著的条件

集成效应在以下情况下**不显著**：
- 单一买家需求量本身很大（自己就能规模经济）
- 每单运输量大且稳定
- 需求大量而稳定

> 即：规模越大、越稳定的企业，外包的集成效应越小。

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 采购≠购买 | Sourcing包含供应商评估、选择、协作、计划全过程 |
| 五大环节 | 评分→选择→协作→购买→分析 |
| 外包决策 | 集成效应 vs 风险 |
| 七大集成 | 能力、库存、3PL运输、仓储运输、仓储设施、采购/合同制造、信息 |
| 集成不显著时 | 需求量大且稳定 → 自建更经济 |
