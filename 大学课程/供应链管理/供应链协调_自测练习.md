## 📝 参考答案

### 一、填空题

1. **最终消费者**（或：终端），**放大**
2. ①**信息障碍** ②**错误激励** ③**运作错误（配给博弈）** ④**错误的行为范式**
3. **配给博弈**
4. **信息共享**；**目标一致性的激励**；**建立相互信任和承诺**

### 二、判断题

| 题号 | 判断 | 解析 |
|------|------|------|
| 1 | ❌ | 信息共享是必要条件但不是充分条件——如果激励结构不变、运作模式不变、行为范式不变，光有数据也不解决问题 |
| 2 | ✅ | sell in（考核推销量）是错误激励；sell through（考核实际售出）是目标一致性激励 |
| 3 | ❌ | PPT说可以通过建立信任和承诺来改变行为范式（契约→互动→发现good will→信任），不是无法改善 |
| 4 | ❌ | 运作障碍不止配给博弈一种——大批量订货、长提前期等在任何供需条件下都可能存在 |
| 5 | ❌ | 互有影响：信任能促进信息共享，信息共享有助于发现运作改进点。PPT将它们并列，但强调"信任是其他手段的催化剂" |

### 三、选择题

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | **A** | 电商平台促销是已知事件——但供应商不知道促销计划（信息不共享），导致误判需求波动。如果供应商提前知道双11计划，就不会把促销旺季当作"需求趋势性增长"。这题的关键是：**信息障碍会导致上游把促销信号误解为需求趋势** |
| 2 | **B** | "按月度批发量返利"是对4S店的错误激励，导致月末集中进货、月初不下单的"曲棍球棒"效应 |
| 3 | **B** | 共享POS数据是信息共享，将预测准确率纳入双方KPI是目标一致性的激励——两项手段同时使用 |
| 4 | **B** | 啤酒游戏的核心教训：问题不在人，在系统设计——仅以订单为信息渠道 + 两周提前期 = 结构性牛鞭效应 |
| 5 | **B** | 未售出面包供应商回收 → 回购合同 → 目标一致性的激励（PPT第18页原例的变体） |

### 四、障碍类型识别

| 场景 | 答案 | 解析 |
|------|------|------|
| ① | **错误激励** | 按季度销售额考核→激励销售人员季末冲量，不考虑下游后果 |
| ② | **信息障碍** | A只看到B的订单数据，不知道B在做促销——"缺少额外信息"（PPT第13页） |
| ③ | **运作错误（配给博弈）** | 芯片短缺→按订单配给→客户虚增订单——典型的配给博弈 |
| ④ | **错误的行为范式** | "只从身边找原因，看不到全局性根本性原因"（PPT第16页原话），各环节互相指责 |
| ⑤ | **错误激励 + 信息障碍** | 物流部门只考核运输成本→激励其拼满整车→牺牲了补货频率。同时物流不知道自己行为对零售的影响（信息/行为双重障碍） |

### 五、管理手段匹配

| ①→A | 共享销售和库存数据 → **信息共享** |
| ②→B | 改变考核指标 → **目标一致性的激励** |
| ③→C | 按实际销量而非订单配给 → **改进运作模式** |
| ④→A+C | 供应商管理库存(VMI) → 以**信息共享**为前提，改变了**运作模式** |
| ⑤→D | 短期交易→长期战略合作 → **建立相互信任和承诺** |
| ⑥→A | 提前通知促销 → **信息共享** |

### 六、简答题要点

**1. 四类障碍的关系**

四类障碍不是孤立的，它们**互相强化**：

- **信息障碍**为其他障碍提供"土壤"：因为各环节不知道全局信息，所以"只从身边找原因"（行为范式）变得合理化
- **错误激励**创造了扭曲行为的"动机"：以 sell in 考核→销售人员故意制造订单波动→上游以为需求真的在变（信息障碍）
- **运作错误**是信息障碍+错误激励的"放大器"：配给博弈下，客户虚增订单的行为是理性的（因为不虚增就吃亏），但这种"局部理性"导致全局混乱
- **错误的行为范式**是**最底层障碍**：如果没有系统思考，即使前三个障碍都改了，人们还是会用新的方式制造失调

> 所以PPT把"错误的行为范式"放在最后一类，不是因为最不重要，而是因为最难改——它是前三类障碍的"文化土壤"。

**2. 四种手段的先后顺序**

PPT的排序暗示了一定的逻辑关系：

1. **信息共享是基础**——没有透明信息，后面三件事都做不了（不知道谁的利益需要对齐、不知道哪些运作需要改进、互不透明谈何信任）
2. **目标一致性的激励是动力**——有了信息，需要用激励设计让各方愿意按全局最优行事
3. **改进运作模式是落地**——信息和激励到位后，具体改流程、改制度、改规则
4. **建立信任和承诺是长效保障**——前三者可以靠制度强制，但没有信任，制度成本极高（需要大量监督和惩罚）。PPT的递进路径"契约→互动→发现good will→信任"说明：信任不能一蹴而就，需要前面三步反复验证。

> 四者不是做完一个忘一个，而是**层层叠加**——信息共享降低了激励对齐的难度，激励对齐降低了运作改进的阻力，运作改进的成功经验积累成信任。

### 七、综合应用题要点

**涉及的障碍**：

| 问题 | 涉及障碍 |
|------|---------|
| 农场主抱怨订单波动 | **信息障碍**：农场主只看订单，不知道电商在做促销活动 |
| 仓库爆仓/空置 | **运作后果**：促销造成需求剧烈波动（信息障碍+可能存在的定价策略问题） |
| 采购经理囤货自保 | **错误的行为范式**：只考虑自己部门不背锅，不考虑囤货如何放大上游波动 |

**四项管理手段的应用**：

| 手段 | 具体措施 |
|------|---------|
| **信息共享** | 将促销计划提前2周同步给农场主和仓库，共享每日终端销量数据，让农场主按实际动销安排采收 |
| **目标一致性的激励** | 采购经理的KPI从"不缺货"改为"缺货率+库存周转率"双指标，或与农场主签订收益共享合同 |
| **改进运作模式** | 促销期间采用预售模式→根据预订单组织采购→避免"拍脑袋囤货"。仓库按预售量做分拨计划 |
| **建立相互信任和承诺** | 与核心农场主从"每次询价比价"转为季度框架协议，约定弹性供货量（±20%可调），降低双方不确定性 |
