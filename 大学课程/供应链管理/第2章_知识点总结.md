# 第2章 分销网络（物流网络）的类型和绩效 —— 知识点总结

> 依据：第2章PPT | 含全部知识点

---

## 一、分销网络的评价指标体系

### 1.1 服务水平（7项指标）

| 指标 | 含义 |
|------|------|
| **响应时间** | 从顾客下达订单到收到产品的时间 |
| **产品多样性** | 发货设施中保有的商品种类数 |
| **产品可得性** | 顾客下单时，发货设施中是否有该产品 |
| **顾客体验** | 下单和收货的方便程度 |
| **新产品面市时间** | 从新品开发完成到铺货到位的时间 |
| **订单可视性** | 顾客跟踪订单全过程的难易程度 |
| **可回收性** | 逆向物流的方便程度 |

### 1.2 运行成本（5项指标）

| 指标 | 含义 |
|------|------|
| **库存成本** | 与库存水平相关的成本（资金占压、维护等） |
| **运输成本** | 产品从一个设施运到另一个设施的成本（与批量、距离、方式相关） |
| **设施成本** | 建设生产车间/仓库的投资及维护成本 |
| **装卸成本** | 分拣、装车、卸货、上架的成本（与装卸次数正相关） |
| **信息系统成本** | 建立和维护信息系统的成本 |

---

## 二、设施数量对各项指标的影响

| 指标 | 随设施数量变化 | 原因 |
|------|:------------:|------|
| 响应时间 | ↓ 缩短 | 设施离顾客更近 |
| 库存成本 | ↑ 上升 | 丧失**库存集成效应**：集中仓库总库存 < 分散仓库总库存之和 |
| 运输成本 | **先↓后↑（倒U形）** | 内向距离↑(运输成本↑)，外向距离↓(运输成本↓)；过多时内向变为零担 |
| 设施成本 | ↑ 上升 | 每个设施都要投资和维护 |
| 装卸成本 | ↑ 上升 | 设施越多，装卸次数越多 |

### 核心结论：总成本呈倒U形曲线

```
总成本
  │   ╲
  │    ╲   ╱
  │     ╲ ╱
  └──────●──→ 设施数量
        最优
```

存在一个**最优设施数量**，使总成本最小。想追求更快响应→增加设施→总成本超过最小值→需评估收入增量是否超过成本增量。

## 三、四种典型分销网络

### 3.1 制造商存货加直送

- 产品从制造商直接发给顾客（如淘宝袜商从工厂发快递）
- 库存位置：制造商
- 特点：**库存成本低**（集中）、产品多样性高、**运输成本高**、响应时间长
- 无内向运输，外向为包裹

### 3.2 分销商存货加包裹承运人交付

- 产品先存到分销商仓库，接到订单后通过快递发货（如亚马逊）
- 库存位置：分销商
- 特点：**响应时间短**、**运输成本低**（内向整车+外向包裹）、库存成本高、设施成本高

### 3.3 制造商存货加直送且在途并货

- 与类型一类似，但在运输途中按收货人合并包裹（如Dell主机+显示器）
- 改进：外向运输从纯包裹变为**批量+包裹**，降低运输成本
- 代价：响应时间变长

### 3.4 分销存货加到户交付

- 分销商存货，采用巡回配送（milk run）方式到户（如桶装水、牛奶配送）
- 特点：外向运输成本极低（巡回合并）

---

## 网络类型对比表

| 维度 | 制造商直送 | 分销商+包裹 | 在途并货 | 分销+到户 |
|------|:--------:|:--------:|:--------:|:--------:|
| 库存位置 | 制造商 | 分销商 | 制造商 | 分销商 |
| 内向运输 | 无 | 整车 | 无 | 整车 |
| 外向运输 | 包裹 | 包裹 | 批量+包裹 | 巡回 |
| 响应时间 | 长 | 短 | 长 | 短 |
| 库存成本 | 低 | 高 | 低 | 高 |
| 运输成本 | 高 | 低 | 中 | 低 |
| 设施成本 | 低 | 高 | 低 | 高 |

---

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 两大体系 | 服务水平(7项) + 运行成本(5项) |
| 库存集成效应 | 集中仓库总库存 < 分散之和 |
| 总成本曲线 | 倒U形，存在最优设施数 |
| 四种网络 | 制造商直送 / 分销商+包裹 / 在途并货 / 分销+到户 |
