# 第一部分：EOQ 经济订货批量

---

## 题1（基础·EOQ公式直接套用）

某公司年需求 D = 36000 件，每次订货成本 S = 200 元，单位持有成本 H = 4 元/件·年。

(a) 求最优订货批量 Q*。
(b) 求年订货次数和订货间隔（按365天算）。
(c) 求年订货成本、年持有成本和年总成本。

---

## 题2（基础·给定价格求EOQ）

某超市每年销售某饮料 12000 箱，采购单价 50 元/箱，每次订货成本 150 元，年持有成本率为单价的 20%。

(a) 求 EOQ。
(b) 若供应商要求每次最少订 500 箱，实际该订多少？总成本比理论EOQ增加多少？

---

## 题3（重点·数量折扣EOQ ★）

某厂年需原料 **300000 kg**，每次订货成本 S=120 元。

| 订货量Q(kg) | 单价(元/kg) |
|:---------:|:---------:|
| Q < 15000 | 2.00 |
| 15000 ≤ Q < 30000 | 1.80 |
| Q ≥ 30000 | 1.60 |

年持有成本率为单价的 25%。

**(a)** 对每个价格区间计算 EOQ，判断是否可行。
**(b)** 对每个可行方案计算年总成本（TC = DP + (D/Q)S + (Q/2)H）。
**(c)** 确定最优订货批量和最低年总成本。

---

## 题4（进阶·含运输成本的EOQ）

某厂年需原料 50000 吨。供方报价：出厂价 800 元/吨，铁路运价 100 元/吨（最低 2000 吨起运），公路运价 180 元/吨（最低 500 吨起运，上限 1500 吨）。每次订货成本 200 元，年持有成本率为到厂价的 20%。

**(a)** 分别计算两种运输方式下的到厂单价（=出厂价+运价）。
**(b)** 分别计算 EOQ。
**(c)** 哪种运输方式总成本更低？

## 题17（综合·运输+安全库存+EOQ的联合决策 ★★★）

某电子产品分销商年销售某型号路由器 **24000台**。采购价 200元/台，年持有成本率为 20%。每次订货的固定行政成本 300元。

# 📝 参考答案与解析

---

## 题1

**(a)** Q* = √(2DS/H) = √(2×36000×200/4) = √3600000 = **1897件**（取整1900件）

**(b)** 年订货次数 = 36000/1897 ≈ 19次；订货间隔 = 365/19 ≈ **19天**

**(c)**
- 年订货成本 = (36000/1897)×200 = 3796元
- 年持有成本 = (1897/2)×4 = 3794元
- 年总成本 = 3796+3794 = **7590元**

> 验证：订货成本≈持有成本，说明EOQ正确。

---

## 题2

**(a)** H = 50×0.20 = 10元
Q* = √(2×12000×150/10) = √360000 = **600箱**

**(b)** 600 > 500，满足约束，实际订 **600箱**。无需调整，总成本不变。

若必须订500箱：TC(500) = 12000/500×150 + 500/2×10 = 3600+2500=6100
TC(600) = 12000/600×150 + 600/2×10 = 3000+3000=**6000**
差额 = 6100-6000 = **100元**

## 题3 ★ 数量折扣

**(a) 各区间EOQ**（D=300000, S=120）

| P | H=0.25P | EOQ=√(2·300000·120/H) | 在区间？ | 可行Q |
|:--:|:------:|:---------------------:|:------:|:----:|
| 2.00 | 0.50 | 12000 | ❌ (需Q<15000, 但12000<15000✅) | **12000** |
| 1.80 | 0.45 | 12649 | ❌ (需Q≥15000) | **15000**(下限) |
| 1.60 | 0.40 | 13416 | ❌ (需Q≥30000) | **30000**(下限) |

补充：P=2.00时EOQ=12000<15000，✅在区间内。

**(b) 总成本** TC = DP + (D/Q)S + (Q/2)H

| Q | P | 采购成本 | 订货成本 | 持有成本 | TC |
|:-----:|:--:|--------:|-------:|-------:|------:|
| 12000 | 2.00 | 600000 | 3000 | 3000 | **606000** |
| 15000 | 1.80 | 540000 | 2400 | 3375 | **545775** |
| 30000 | 1.60 | 480000 | 1200 | 6000 | **487200** |

**(c)** 最优 Q* = **30000 kg**，最低年总成本 **487200元**。

## 题4

**(a) 到厂单价**

铁路：P_rail = 800+100 = 900元/吨
公路：P_road = 800+180 = 980元/吨

**(b) EOQ**

H_rail = 900×0.2 = 180；Q*_rail = √(2×50000×200/180) = √111111 = **333吨**
→ 不足铁路最低2000吨 → 取 **Q_rail = 2000吨**

H_road = 980×0.2 = 196；Q*_road = √(2×50000×200/196) = √102041 = **319吨**
→ 不足公路最低500吨 → 取 **Q_road = 500吨**

**(c) 总成本对比**

铁路：TC = 50000×900 + (50000/2000)×200 + (2000/2)×180 = 45000000+5000+180000 = **45185000元**

公路：TC = 50000×980 + (50000/500)×200 + (500/2)×196 = 49000000+20000+49000 = **49069000元**

✅ **铁路更优**（单价低+批量大虽库存成本高但被运价优势抵消）。

**(b)** ss = F⁻¹(CSL) × σ_L = 1.65 × 160 = **264件**

**(c)** D_L = 400×4 = 1600件；ROP = 1600 + 264 = **1864件**

## 题6

**(a)** ss_new = 2.33 × 160 = **372.8件**（≈373件）

**(b)** 增幅 = (373-264)/264 = **41.3%**

**(c)** CSL仅提升4个百分点(95%→99%)，安全库存暴涨41%。说明**高服务水平的边际成本急剧上升**——每提高1%可得性，需要不成比例的安全库存增长。

## 题7

**(a)** σ_L_new = 80 × √1 = 80件；ss_new = 1.65 × 80 = **132件**

**(b)** 132/264 = **50%**——安全库存减半！

## 题9 ★

**(a)** σ_L = √(L·σ_D² + D²·s_L²) = √(3×50² + 200²×1²) = √(7500+40000) = √47500 ≈ **217.9件**

**(b)** ss = 1.88 × 217.9 ≈ **410件**

**(c)** s_L=0时：σ_L = √(3×2500) = √7500 ≈ 86.6件；ss_det = 1.88×86.6 ≈ **163件**

差额 = 410-163 = **247件**，增加了151%！

## 题10 ★★ 库存集成

**(a) 分散**

每个仓库：σ_L = 120×√2 ≈ 169.7件；ss = 1.65×169.7 ≈ **280件**

4仓库总ss = 4×280 = **1120件**

**(b) 集中（ρ=0）**

总需求均方差：σ_D_total = √(4×120²) = 120×√4 = **240件/周**（注意：不是4×120！）

提前期内：σ_L_total = 240×√2 ≈ 339.4件

总ss = 1.65×339.4 ≈ **560件**

**(c)** 减少 = (1120-560)/1120 = **50%**

若ρ=1：σ_D_total = √(4×120² + 4×3×1×120²) = √(57600+172800) = 480 = 4×120。
总ss = 1120，与分散相同——**完全正相关时库存集成无效**。

## 题14 ★★ 回购合同

**(a)** Co_new = w - b = 4-2 = **2元**；Cu = 6元不变

**(b)** CSL* = 6/(6+2) = **0.75**

**(c)** 累计：80→0.3, 100→0.7, 120→1.0。0.75 → 订 **120份**（比之前的100份增加了）。

**(d) 报摊利润变化**

**回购前（Q=100）**：
- 需求80(0.3)：利=80×10-100×4=800-400=400
- 需求100(0.4)：利=100×6=600
- 需求120(0.3)：利=100×6=600（缺货20，但仍只卖了100）
- 期望=0.3×400+0.4×600+0.3×600 = 120+240+180 = **540元**

**回购后（Q=120）**：
- 需求80(0.3)：收入=80×10+40×2=880，成本=120×4=480，利=400
- 需求100(0.4)：收入=100×10+20×2=1040，成本=480，利=560
- 需求120(0.3)：收入=120×10=1200，成本=480，利=720
- 期望=0.3×400+0.4×560+0.3×720 = 120+224+216 = **560元**（+20元）

**(e) 出版商利润**（生产成本=2元/份）

回购前（Q=100）：无论需求多少，利=100×(4-2)=**200元**

回购后（Q=120）：
- 需求80：收入=120×4=480，回购=40×2=80，成本=120×2=240，利=480-80-240=**160元**
- 需求100：利=480-40-240=**200元**
- 需求120：利=120×4-120×2=**240元**
- 期望=0.3×160+0.4×200+0.3×240 = 48+80+72 = **200元**

> 出版商利润不变，但报摊利润增加20元 → **回购合同可以帕累托改进**（一方更好而另一方不更差）。实际中通常会设计回购价使双方都更好。

## 题15 设计回购价

**(a) 无回购**：Cu = 12-7 = 5，Co = 7-0 = 7，CSL* = 5/(5+7) = 0.417
累计：80→0.4(≥0.417)→ 订 **80个**

报摊利润（Q=80）：利润恒=80×5=**400元**
品牌方利润（Q=80）：利=80×(7-3)=**320元**

**(b) 诱导订150个**，需使Q=150期望利润 ≥ Q=80期望利润(=400)

设回购价b。Co' = 7-b，Cu = 5不变。

Q=150期望利润：
- 需求80(0.4)：收入=80×12+70×b=960+70b，成本=150×7=1050，利=70b-90
- 需求150(0.6)：利=150×5=750
- 期望 = 0.4(70b-90) + 0.6×750 = 28b-36+450 = 28b+414

令 28b+414 ≥ 400 → 28b ≥ -14 → b ≥ -0.5

b≥0即有解。取 **b=2元**（品牌方还能赚：3-2=1元/个回收利润）：
验证：Q=150期望=28×2+414=470 > 400 ✅，报摊会订150个。

**(c) b=2时品牌方利润**：
- 需求80：150×7-150×3-70×2=1050-450-140=460
- 需求150：150×(7-3)=600
- 期望=0.4×460+0.6×600=184+360=**544元** > 320元 ✅

> 双方利润都提高了！回购合同实现了供应链协调。

## 题17 ★★★ 综合题

**(a) 到厂单价**

铁路：200+5 = **205元/台**
公路：200+12 = **212元/台**

**(b) EOQ及调整**

铁路：H=205×0.2=41元，Q*=√(2×24000×300/41)=√351220≈**593台**→不足最低1000→ Q=**1000台**

公路：H=212×0.2=42.4元，Q*=√(2×24000×300/42.4)=√339623≈**583台**→在200-1500内→ Q=**583台**

**(c) 安全库存**

日需求 = 24000/365 ≈ 65.75台/天
周需求 = 462台/周

铁路：提前期 = (1+6)/7 = 1周。σ_L = 150×√1 = 150
ss = 2.05×150 = **307.5台**；成本 = 307.5×41 = **12608元**

公路：提前期 = (1+2)/7 ≈ 0.429周。σ_L = 150×√0.429 ≈ 98.2
ss = 2.05×98.2 ≈ **201.4台**；成本 = 201.4×42.4 = **8539元**

**(d) 总成本**

| 成本项 | 铁路(Q=1000) | 公路(Q=583) |
|--------|:---------:|:---------:|
| 采购成本 | 24000×205=4920000 | 24000×212=5088000 |
| 订货成本 | 24000/1000×300=7200 | 24000/583×300=12357 |
| 周转库存 | 1000/2×41=20500 | 583/2×42.4=12360 |

✅ **铁路总成本更低**（约509.6万 vs 541.5万），尽管安全库存和在途库存更高，但采购差价(205-212=7元×24000=16.8万)+运价差(5-12=7元×24000=16.8万)合计33.6万，远超库存成本的差额。
