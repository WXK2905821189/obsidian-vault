# 第1章 供应链与供应链管理 —— 知识点总结

> 依据：第1章PPT | 含全部知识点

---

## 一、什么是供应链

### 1.1 定义
供应链由满足顾客需求所**直接或间接**地涉及到的所有组织构成一个网链。

### 1.2 供应链上的三种流

| 流类型 | 内容 | 方向 |
|--------|------|------|
| **产品流** | 原材料→零部件→成品，以及反向的退货/回收 | 上游→下游（正向）；下游→上游（逆向） |
| **信息流** | 订单信息、需求预测、库存水平、配送计划 | 双向 |
| **资金流** | 商品价款、货款结算 | 下游→上游 |

> ⚠️ 不能简单把供应链上的流等同于物流。信息流和资金流同样重要。

### 1.3 抽象供应链的环节

```
供应商 → 制造商 → 批发商/分销商 → 零售商 → 顾客
```

现实中的供应链可能**缺失或增加**某些环节（如Dell直销跳过批发商和零售商）。

---

## 二、供应链管理

### 2.1 为什么要管理

1. 多环节间流动着多种流（信息、资金、物料），要保证它们在需要的时间、按需要的数量、到达需要的位置——**复杂**
2. 供应链由不同利益主体构成，各方有各自的期望——**需要协调**

> 例：供应商希望少频次大批量运输（省运费）；买方希望多频次小批量运输（降库存）。

### 2.2 谁来管理——核心企业

每条供应链通常存在一个**强势企业**（核心企业），是事实上的管理者。

- 汽车行业：整车制造商是核心企业
- 零售行业：沃尔玛是核心企业

> 但供应链上**任何一个企业**都希望对上下游施加影响，因此都需要供应链管理知识。

### 2.3 管理目标——供应链整体利润最大化

> 为什么不是焦点企业利润最大化？
> → 因为长期来看，整体利润最大化才能保证每个环节的持续健康发展。

**供应链利润 = 供应链收入 - 供应链成本**

| 收入端 | 成本端 |
|--------|--------|
| 销售价格 | 生产成本（不含内部原料采购） |
| 销售数量 | 仓储成本 |
| 产品质量 | 运输成本 |
| 服务水平 | 信息成本、资金运动成本 |

## 三、战略匹配：服务水平与成本的权衡

### 3.1 基本矛盾

服务水平和成本是**此消彼长**的关系：

| 提高服务水平的方法 | 导致的成本增加 |
|------------------|--------------|
| 多备库存避免缺货 | 库存成本↑ |
| 用空运代替铁路 | 运输成本↑ |
| 将仓库建在离顾客近的地方 | 设施成本↑、库存成本↑（分散） |

### 3.2 成本-响应性前缘面

```
响应性(服务水平) ↑
                 │  ··前缘面··
                 │ ╱
                 │╱
                 └──────────→ 效率性(成本)
```

在"前缘面"上选择一个点，使**收入-成本之差**最大化。

### 3.3 战略匹配：隐含不确定性

供应链的性能表现（响应-效率组合）要匹配目标市场的**隐含不确定性**。

| 产品类型 | 隐含不确定性 | 需要的供应链 |
|---------|------------|------------|
| 劳保服装（款式长期不变） | 低 | 效率型 |
| 职场服装（款式每年有变化） | 中 | 居中 |
| 时尚女装（款式年年变、需求难预测） | 高 | 响应型 |

## 四、供应链六大驱动因素

| 驱动因素 | 含义 | 关键决策 |
|---------|------|---------|
| **设施** | 生产/存储的地理位置 | 选址、数量、产能 |
| **库存** | 原材料、在制品、成品 | 订多少、何时订、安全库存 |
| **运输** | 产品在网络中的移动 | 运输方式、路线、网络设计 |
| **信息** | 供应链各环节的数据 | 共享什么、与谁共享、用什么技术 |
| **采购** | 谁来做（自制vs外包） | 供应商选择、合同设计 |
| **定价** | 商品/服务的价格策略 | 固定价、折扣、促销 |

> 📌 六大驱动因素相互影响。例如：设施多→运输短→库存可少→信息要跟上。

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 供应链定义 | 直接+间接涉及的所有组织 |
| 三种流 | 产品流、信息流、资金流 |
| 管理目标 | **整体利润最大化** |
| 战略匹配 | 隐含不确定性 → 响应性/效率性定位 |
| 六大驱动 | 设施、库存、运输、信息、采购、定价 |
