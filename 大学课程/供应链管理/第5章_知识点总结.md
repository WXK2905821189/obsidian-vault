## 一、供应链失调与牛鞭效应

### 1.1 牛鞭效应定义

需求信息从最终消费者向上游传递时，订单波动**逐级放大**的现象。

**案例**：
- 宝洁"帮宝适尿布"：消费者需求波动很小，原材料订单波动很大
- 百味来(Barilla)：超市→DC订单波动不到3倍，DC→工厂订单波动达**70倍**
- 计算机产业链：内存条、硬盘周期性积压或缺货

### 1.2 形成机制

1. 供应链每一环节**仅根据相邻下游的订单流**来预测需求变化趋势
2. 根据上述变化趋势决定自身的采购（或生产）量

> 核心：各环节独立做基于订单的预测 → 波动逐级放大

### 1.3 失调对绩效的影响

| 影响 | 表现 |
|------|------|
| 成本增加 | 上游被迫建立高产能或高库存；产能上去后订单反而下降 |
| 产品可得性下降 | 下游订单大增时上游来不及反应，造成缺货 |
| 提前期延长 | 缺货→延迟交货→提前期变长 |
| 运输/装卸成本上升 | 为应对订单波动准备冗余运力 |
| 关系紧张 | 各环节互相指责（"你们订单忽高忽低" vs "你们总是缺货"） |

## 二、制约供应链协调的四类障碍

| 障碍类型 | 核心问题 | 具体表现 |
|---------|---------|---------|
| **信息障碍** | 各看各的数据 | 仅以订单为唯一信息来源；缺少信息共享；基于已接收订单预测需求 |
| **错误激励** | 考核驱动扭曲 | 企业内：按sell in考核→销售人员月末冲量；企业间：整车厂年终向4S店打折 |
| **运作错误（配给博弈）** | 制度漏洞 | 产品短缺时按订单比例配给→下游虚增订单 |
| **错误的行为范式** | 思维模式 | 不考虑对他人的影响；只从身边找原因；互不信任；没有系统思考习惯 |

### 配给博弈示例（PPT第15页）

| | 零售商A不虚增 | 零售商A虚增 |
|------|:----:|:----:|
| A订货量 | 50 | **90** |
| B订货量 | 50 | 50 |
| A配给量 | 50 | **60** |
| B配给量 | 50 | 40 |

> A虚增订单→获得更多配给→B吃亏→下次B也虚增→恶性循环

## 三、供应链协调的四种管理手段

| 管理手段         | 核心动作       | 典型做法                               |
| ------------ | ---------- | ---------------------------------- |
| **信息共享**     | 让所有人看到同一张图 | 共享POS数据（需求率、库存、促销）；联合预测；协商综合计划     |
| **目标一致性的激励** | 让局部利益对齐全局  | 企业内：sell through代替sell in；企业间：回购合同 |
| **改进运作模式**   | 堵住制度漏洞     | 配给博弈→基于实际销量（而非订单）配给                |
| **建立信任和承诺**  | 长期关系替代短期博弈 | 契约→互动→发现good will→信任和承诺            |

### 回购合同（PPT第18页）（属于目标一致性的激励）

- 供应商承诺以一定价格回购零售商未售出的商品
- 适用于**易逝品**（报纸、面包、时装）
- 降低了零售商的过剩风险→零售商更敢多进货→**双方利润都增加**

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 牛鞭效应 | 需求波动从下游→上游逐级放大 |
| 形成机制 | 各自基于订单预测→逐层放大 |
| 四类障碍 | 信息障碍、错误激励、运作错误(配给博弈)、错误行为范式 |
| 四种手段 | 信息共享、目标一致激励、改进运作、建立信任 |
| 回购合同 | 分担零售商的过剩风险→增加订货量→双方利润↑ |
