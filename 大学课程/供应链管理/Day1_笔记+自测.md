## 一、牛鞭效应 (Bullwhip Effect) ★必考

### 概念卡片

**一句话定义**：订单的波动幅度沿供应链向上游逐级放大的现象。

**生活化例子**：你开奶茶店每天卖100杯。某天卖了120杯。怕不够，向供应商订150杯。供应商以为市场爆发，向工厂订200杯。工厂扩产到250杯/天。第二天回到100杯 — 整个供应链为虚假繁荣付出了代价。

**学科例子（宝洁）**：帮宝适尿布 — 零售终端波动很小 → 批发商订单波动大 → 宝洁向原料商订单波动更大。消费者需求几乎没变！

**学科例子（百味来）**：超市对DC订单波动 <3倍 → DC向工厂订单波动70倍！

> ❓ **自我解释**：为什么订单波动会逐级放大？
>
> → 每个环节只根据相邻下游订单预测趋势（而非终端真实需求），每一级在上一级波动上再放大。传话游戏效应。

### 🔗 关联

- 牛鞭效应 → 需求不确定性↑ → 安全库存(第7章)↑ → 总库存成本↑
- 牛鞭效应 → 上游必须建更高产能 → 设施成本↑

---

## 二、牛鞭效应形成机制（2步骤）

1. **Step 1**：每个环节只根据**相邻下游**的订单流预测需求变化趋势
2. **Step 2**：根据上述趋势决定自身采购/生产量

> 结果：下游微小趋势 → 上游逐级放大

---

## 三、四类失调障碍 ★必考记忆

| 障碍类型      | 核心问题                | 典型表现                                             | 关键词    |
| --------- | ------------------- | ------------------------------------------------ | ------ |
| 🔴 信息障碍   | 只看订单不看终端真实需求        | 啤酒游戏：各环节都在猜，没人知道消费者真正买了多少                        | 信息不共享  |
| 🟡 错误激励   | 考核指标引导错误行为          | 企业内：考核 sell-in（批发量）而非 sell-through（终端销量）→ 月底疯狂压货 | 考核错配   |
| 🟠 配给博弈   | 供不应求时按订单比例分配 → 虚增订单 | 只有100件货，A虚增到90拿60件，B老实订60只得40件                   | 虚增订单   |
| 🔵 错误行为范式 | 缺乏系统思考              | 互不信任，只从身边找原因，不思考全局                               | 系统思考缺失 |

> 🧠 **记忆术** — 四障碍首字：**信·激·配·行**（信息→激励→配给→行为）

## 四、协调管理手段

1. **信息共享** — POS数据、促销信息、联合预测（替代各自猜各自）
2. **拉齐激励** — 考核 sell-through 替代 sell-in；回购合同

4. **建立信任与承诺** — 互信 → 分享信息 → 减少重复 → 缩短响应
信息共享——拉齐激励——改进运作模式——建立信任与承诺

# 第1章 供应链与供应链管理

### 概念卡片：供应链

**一句话定义**：由**满足顾客需求**所直接或间接涉及的所有组织构成的网链。

**生活化例子**：买一瓶可乐 → 超市（零售）→ 配送中心（分销）→ 装瓶厂（制造）→ 糖浆/瓶子/标签厂 → 原材料供应商。整条链就是供应链。

---

## 一、三种"流"

- **产品流** — 供应商到顾客（正向）+ 退货回收（逆向）
- **信息流** — 订单、计划、预测在各环节间传递
- **资金流** — 付款、信用、结算在各企业间流动

> ⚠️ **重要！** 供应链上的流 ≠ 物流！物流只是产品流的一部分。

---

## 二、五个典型环节

```
顾客 → 零售商 → 批发商/分销商 → 制造商 → 零部件/原材料供应商
```

- 不一定都包含全部五个环节，可缺失或增加
- **核心企业**：供应链上影响力最强、事实上的管理者（如汽车行业：整车厂）

---

## 三、管理目标

> 🎯 **总目标：供应链整体利润最大化 ≠ 焦点企业利润最大化！**

供应链整体利润 = 销售收入 − 总成本（生产 + 仓储 + 运输 + 信息 + 资金运动）

---

## 四、战略匹配 ★核心概念

基本矛盾：**服务水平（响应性）↑ → 成本 ↑**（此消彼长）

| 市场类型 | 隐含不确定性         | 需要的供应链 |
| ---- | -------------- | ------ |
| 时尚女装 | 高（款式年年变、需求难预测） | 高响应供应链 |
| 劳保服装 | 低（长期不变、需求稳定）   | 效率型供应链 |

> 🎯 **战略匹配**：高不确定性市场 → 高响应供应链；低不确定性 → 高效率供应链

> ❓ **自我解释**：如果用高效率供应链服务高不确定性市场，会怎样？
>
> → 频繁缺货（产能跟不上波动）、响应太慢（顾客等不了）、错失销售。效率再高，货卖不出去也白搭。

---

# 第6章 周转库存（EOQ 模型）★考试计算必考

### 概念卡片：周转库存

**一句话定义**：两次补充库存期间用来满足顾客需求的库存，平均值 = Q/2。

**例子**：便利店每次进100箱水，卖完再进100箱。两次进货之间仓库平均有50箱 = 周转库存。

---

## 一、三个关键参数

- **D** = 需求率（单位时间需求量，如 件/年）
- **S** = 每次订货成本（与数量无关的固定成本，如运输费、检验费）
- **h** = 持有成本系数（库存一年花的钱占单价的百分比，如 h=0.2）

---

## 二、EOQ 推导逻辑

```
总相关成本 = 订货成本 + 持有成本

订货成本 = (D/Q) × S     → Q↑ → 次数↓ → 订货成本↓
持有成本 = (Q/2) × hC    → Q↑ → 库存↑ → 持有成本↑

一种升、一种降 → 存在最优 Q 使总成本最小！
```

### 🎯 核心公式（必须背）

$$Q^* = \sqrt{\frac{2DS}{hC}}$$

**例题**：D=12000件/年, S=4000元/次, C=500元/件, h=0.2

$$Q^* = \sqrt{\frac{2 \times 12000 \times 4000}{0.2 \times 500}} = \sqrt{\frac{96,000,000}{100}} = \sqrt{960,000} \approx 980 \text{件}$$

> ❓ **自我解释**：为什么 S 在分子、h 在分母？
>
> → S大 = 每次订货贵 → 少订几次每次多订 → Q变大。
> → h大 = 持有贵 → 少存 → Q变小。方向都对！

---

## 三、有批量折扣的订货决策

**场景**：供应商说「订5000以上单价2.96元，订10000以上单价2.92元」— 要不要多订？

**解题三步走**：

1. **Step 1**：每个价格区间分别算 Q\*（用对应价格代入 EOQ 公式）
2. **Step 2**：调整到有效区间（超出左 → 取左边界；超出右 → 取右边界；落在内 → 直接用）
3. **Step 3**：算每个方案的 TC = (D/Q)S + (Q/2)hC + DC，**选最小的！**

> D=120000/年, S=100, h=0.2
> - Q<5000, C=3.00 → Q\*≈6325 超出区间 → 取5000
> - 5000≤Q<10000, C=2.96 → Q\*≈6367 落在区间内 → 取6367
> - Q≥10000, C=2.92 → Q\*≈6410 低于区间 → 取10000
> - **比较 TC(5000), TC(6367), TC(10000) → 选最小 → 10000件**

---

## 四、供应链协调中的批量折扣

- 零售商按自身 EOQ 订货 → 批量可能偏离供应链整体最优
- 制造商用批量折扣诱导零售商提高订货量 → 降低供应链总成本
- 制造商从节省中拿出部分补偿零售商增加的库存成本

---

## 五、协调订货时间点

- **同步补货**：批发商补货的同时向零售商发货 → 总库存最低 = Q/2
- **整数倍关系**：批发商周期 = 零售商的整数倍 → 显著降低总库存

# 第7章 安全库存 ★考试计算必考

### 概念卡片：安全库存

**一句话定义**：为满足超出预测量的需求而额外持有的库存。订货到达时仓库中尚存的商品数量。

**生活化例子**：预计明天卖100杯奶茶，怕多来人，多备30杯料 = 安全库存。平时不动用，只在超需求时才动用。

**学科内例子**：超市预计每周卖200箱（Q/2=100周转），但怕某周卖250，多备30箱安全库存。平均库存=100+30=130。

---

## 一、补货政策对比

|            | 永续盘存（连续盘点）     | 周期盘点（定期盘存）    |
| ---------- | -------------- | ------------- |
| **触发方式**   | 库存降到 ROP 时立即订货 | 每隔固定时间 T 盘点一次 |
| **订货批量**   | 固定 Q           | 不固定           |
| **覆盖波动时长** | 仅提前期 L         | **T+L**（更长！）  |
| **安全库存水平** | **较低**         | **较高**        |

---

## 二、核心公式 ★必须背

### 前提假设

- 每周需求 d ~ N(D, σ²)：均值为 D，标准差为 σ 的正态分布
- 订货提前期为 L 周，L 周内总需求 dL ~ N(LD, Lσ²)
- **关键**：提前期内需求标准差 **σL = √L × σ**

### 仅需求不确定

$$ss = \sqrt{L} \cdot \sigma \cdot F^{-1}(CSL)$$

**F⁻¹(CSL) 查表值：**

| CSL | F⁻¹(CSL) |
|-----|----------|
| 90% | **1.28** |
| 95% | **1.65** |
| 97% | **1.88** |
| 99% | **2.33** |

**例题**：D=100件/周, σ=30件/周, L=4周, CSL=95%

$$ss = \sqrt{4} \times 30 \times 1.65 = 2 \times 30 \times 1.65 = 99 \text{件}$$

> ❓ **自我解释**：L从1变4，σL为什么是 2σ 而不是 4σ？
>
> → 每周需求相互独立。4周**方差** = 4σ²（方差可加），**标准差** = √(4σ²) = 2σ。**不是4σ！经典易错点！**

### 供给也波动

$$ss = \sqrt{L \cdot \sigma^2 + D^2 \cdot s_L^2} \cdot F^{-1}(CSL)$$

sL = 提前期自身的标准差（供应商有时准时有时延误）

---

## 三、库存集成

> 🎯 **集中仓库安全库存 < 分散仓库安全库存之和** — 当各地区需求不完全正相关时

**例子**：4街区各有便利店，每家备5件 → 总安全库存20件。合并为中央仓库，街区间波动互相抵消 → 总安全库存只要12件！

需求相关性（ρ）越低，集成效果越好。ρ=0 最佳，ρ=1 无效果。

---

## 四、降低安全库存的四条途径

1. **压缩提前期 L** — 需供应商配合（关键是让供应商也受益）
2. **减少需求波动 σ** — 信息共享替代各自预测
3. **减少供给波动 sL** — 供应商用 ERP 提前知道订货信息
4. **库存集成** — 合并仓库、合并服务对象
