## 一、简答题（40分）

### 1. 六个驱动因素分类（10分）

供应链六大驱动因素：**设施(Facilities)、库存(Inventory)、运输(Transportation)、信息(Information)、采购(Sourcing)、定价(Pricing)**。

| 序号  | 决策描述        | 驱动因素                    | 理由                             |
| --- | ----------- | ----------------------- | ------------------------------ |
| (1) | 每周订购→按订货点订货 | **库存 (Inventory)**      | 改变了订货策略，涉及何时订货、订多少的库存管理决策      |
| (2) | 发货仓库下沉到县级城市 | **设施 (Facilities)**     | 改变了仓库的选址和网络布局，属于设施选址与数量决策      |
| (3) | 公路运输→铁路运输   | **运输 (Transportation)** | 改变了运输方式，涉及运输模式选择决策             |
| (4) | 自制面食→向面点厂采购 | **采购 (Sourcing)**       | 自制转外购（make-or-buy决策），属于采购/外包决策 |
| (5) | 引入ERP系统     | **信息 (Information)**    | ERP是信息系统，改变了信息的收集、处理和共享方式      |

### 2. YT水泥公司运输网络选择（10分）

**建筑工地客户** → 应采用 **网络A（直运网络 / Direct Shipping）**

**理由**：
- 建筑工地需求特点：每次运输**量大**且要求**快速交货**
- 直运网络：产品从工厂直接运到客户，**无中间停留**，速度最快
- 大批量运输使得车辆利用率高，直运也是经济的选择

**装修材料商店** → 应采用 **网络B（巡回运输 / Milk Run）**

**理由**：
- 装修商店需求特点：每次进货量**很小**，且**不在意交货时间**
- Milk Run：一辆卡车依次访问多个商店，**合并小批量货物**
- 避免了每个商店单独派车的浪费，显著**降低运输成本**
- 多个小批量客户采用Milk Run可实现运输规模经济

> **核心原理**：批量大+急 → 直运（速度优先）；批量小+不急 → 巡回（成本优先）

### 3. 永续盘存系统下安全库存的影响因素（10分）

**导致安全库存上升的因素**（来自公式 `ss = F⁻¹(CSL) × σ × √L`）：

| 因素 | 方向 | 解释 |
|------|------|------|
| **需求标准差 σ ↑** | ss ↑ | 需求波动越大，越需要更多缓冲 |
| **提前期 L ↑** | ss ↑ | 提前期越长，期间累积的不确定性越大 |
| **服务水平 CSL ↑** | ss ↑ | 要求越高，F⁻¹(CSL)越大，安全库存越多 |
| **提前期不确定性 ↑** | ss ↑ | 供货不稳定迫使增加安全库存 |

**降低安全库存的方法**：

| 方法                     | 作用原理                             |
| ---------------------- | -------------------------------- |
| **缩短提前期 L**            | 直接减小 √L，降低提前期内需求不确定性             |
| **信息共享**               | 与供应商共享需求数据，减少需求信息扭曲              |
| **聚集库存（库存集中化）**        | 利用 √n 法则：分散n处总安全库存 = √n × 单处安全库存 |
| **减少需求波动**             | 通过促销管理、日常低价等策略平稳需求               |
| **提高预测精度**             | 缩小 σ，降低需求不确定性                    |
| **推迟策略(Postponement)** | 将差异化环节推迟到需求明确后                   |
| **供应商管理库存(VMI)**       | 供应商直接管理库存，减少信息扭曲和牛鞭效应            |

### 4. HP公司进一步扩大外包的风险（10分）

HP将采购职能也外包给合同制造商后，面临以下风险：

| 风险 | 具体表现 |
|------|---------|
| **供应链失控风险** | 失去对供应商选择和质量把控的话语权，完全依赖合同制造商 |
| **信息泄露风险** | 采购数据暴露产品配方、成本结构、供应商名单等核心商业机密 |
| **被"架空"风险** | 合同制造商掌握制造+采购全链条，可能绕过HP直接面向市场 |
| **协调成本上升** | 原本HP内部协调的制造-采购环节变成跨组织协调 |
| **质量风险** | 合同制造商可能为了压低采购成本而牺牲原材料质量 |
| **供应链中断风险** | 丧失对二级供应商的管理，未预料的中断难以快速响应 |
| **隐性成本** | 外包看起来便宜，但监管、协调、质量检验等隐性成本被低估 |
| **创新受限** | 失去制造和采购环节的学习效应，长期创新能力下降 |
| **牛鞭效应加剧** | HP与制造商之间多一层信息传递，需求信息扭曲加剧 |

## 二、计算题（30分）

### 1. 数量折扣下的最优订货量（15分）

**已知数据**：
- 月需求 D_月 = 20000 斤 → **年需求 D = 240000 斤**
- 订货成本 S = 100 元/次
- 持有成本率 h = 0.2 × 价格

| 数量区间 | 单价 P（元/斤） | 持有成本 H=h×P |
|----------|---------------|----------------|
| Q < 20000 | 1.20 | 0.24 |
| 20000 ≤ Q < 40000 | 1.10 | 0.22 |
| Q ≥ 40000 | 1.00 | 0.20 |

**步骤1：对每个价格区间计算 EOQ**

EOQ 公式：`Q* = √(2DS/H)`

| 价格 | H | Q*（计算值） | 是否在区间内？ | 可行订货量 |
|------|---|-------------|--------------|-----------|
| 1.20 | 0.24 | √(2×240000×100/0.24) = 14142 | ✅ 14142 < 20000 | **Q = 14142** |
| 1.10 | 0.22 | √(2×240000×100/0.22) = 14771 | ❌ 14771 < 20000 | **Q = 20000**（取下限） |
| 1.00 | 0.20 | √(2×240000×100/0.20) = 15492 | ❌ 15492 < 40000 | **Q = 40000**（取下限） |

**步骤2：计算每个可行方案的总成本**

总成本公式：`TC = D×P + (D/Q)×S + (Q/2)×H`

**方案一：Q = 14142，P = 1.20，H = 0.24**
```
订货成本 = (240000/14142) × 100 = 1697.0
库存成本 = (14142/2) × 0.24    = 1697.0
采购成本 = 240000 × 1.20       = 288000.0
────────────────────────────────────
总成本   = 291394.1 元
```

**方案二：Q = 20000，P = 1.10，H = 0.22**
```
订货成本 = (240000/20000) × 100 = 1200.0
库存成本 = (20000/2) × 0.22     = 2200.0
采购成本 = 240000 × 1.10        = 264000.0
────────────────────────────────────
总成本   = 267400.0 元
```

**方案三：Q = 40000，P = 1.00，H = 0.20**
```
订货成本 = (240000/40000) × 100 = 600.0
库存成本 = (40000/2) × 0.20     = 4000.0
采购成本 = 240000 × 1.00        = 240000.0
────────────────────────────────────
总成本   = 244600.0 元  ← 最优！
```

| 方案 | 订货量 | 单价 | 总成本 |
|------|--------|------|--------|
| 一 | 14142 | 1.20 | 291394 |
| 二 | 20000 | 1.10 | 267400 |
| **三** | **40000** | **1.00** | **244600 ✅** |

> **答案**：最优采购批量 **Q* = 40000 斤**，此时享受最低单价 1.00 元/斤，年总成本 244600 元。

> ⚡ **考试技巧**：数量折扣题必须三个价格都算，不在区间的EOQ用区间边界值代替。最终比较总成本决定。

### 2. 设施选址决策模型（15分）

**决策变量**：
- `yᵢ ∈ {0,1}` — 是否在 i 地建厂（i = 1,2,...,m）
- `xᵢⱼ ≥ 0` — 从工厂 i 到市场 j 的运输量

**目标函数**（供应链总利润最大化）：

```
Max  Π = Σⱼ Rⱼ·Dⱼ   -   Σᵢ Fᵢ·yᵢ   -   Σᵢ Σⱼ cᵢⱼ·xᵢⱼ
         └─总收入─┘     └─固定成本─┘    └─可变成本(生产+运输)─┘
```

其中 Rⱼ 为市场 j 的销售价格，Dⱼ 为需求量。

**约束条件**：

**(1) 需求满足**：`Σᵢ xᵢⱼ = Dⱼ`，∀j

**(2) 产能限制**：`Σⱼ xᵢⱼ ≤ Kᵢ·yᵢ`，∀i （Kᵢ为工厂i的产能）

**(3) 供货量限制**：`xᵢⱼ ≤ Dⱼ·yᵢ`，∀i,j（不建厂则不能供货）

**(4) 非负与整数**：`xᵢⱼ ≥ 0`，`yᵢ ∈ {0,1}`

> **与成本最小化模型的区别**：当各市场价格不同时，目标是**利润最大化**而非成本最小化——高价格市场即使成本高也可能值得服务。

## 三、案例分析：Seven-Eleven Japan（30分）

### 1. 提升供应链响应性的措施（10分）

**响应性 = 快速满足顾客需求的能力**。Seven-Eleven Japan 的例证：

| 措施 | 例证 |
|------|------|
| **高频补货** | 盒餐/饭团每日订货3次，面包每日2次 → 确保新鲜、快速响应三餐需求 |
| **快速信息传递** | 门店订单"立即传送到供应商和配送中心"，供应商即时组织生产 |
| **密集开店** | 在爱知县一年新增108家门店 → 缩短配送距离，贴近消费者 |
| **供应商反应速度** | 供应商在接到所有门店订单后才开始生产 → 按需生产，避免过量 |
| **灵活的订货终端** | 手持图形化订货终端，门店经理边巡视边下单 → 实时响应货架变化 |
| **配送中心越库操作** | 快餐食品在DC不持有库存 → 货物不停留，直接中转 |
| **Milk Run快速配送** | 信任交接（不等扫描完就发车）→ 缩短每站时间，加速整体配送 |
| **专属供应商+车队** | 290个专属供应商+三井专属车队 → 保证产能和运力即时可用 |

### 2. 提升供应链效率性的措施（10分）

**效率性 = 以最低成本提供既定服务水平**。Seven-Eleven Japan 的例证：

| 措施 | 例证 |
|------|------|
| **密集开店策略** | 不全国铺开而集中区域密集开店 → **提高配送效率**，提升品牌知名度 |
| **Milk Run巡回运输** | 一辆卡车依次访问多家门店 → "节省所需卡车总体数量"，**减少运输成本** |
| **供应商预分拣** | 供应商发货时已按门店+品种分别包装 → "大大缩短配送中心配货操作时间" |
| **统一订货截止时间** | 所有门店晚餐订货在上午10点前 → 供应商可**批量集中生产**，降低生产成本 |
| **配送中心双重功能** | 快餐食品作cross-dock（不持库存），非快餐食品作仓储中心 → **差异化库存策略** |
| **分区管理** | 293个地区DC覆盖各自区域 → 减少跨区运输，降低运输距离 |
| **差异化补货周期** | 不同商品不同订货频率 → 避免"一刀切"造成的资源浪费 |
| **基于信任的交接** | 不等扫描完成 → 减少每站停留时间，提高车辆周转率 |

### 3. 信息系统提升的供应链绩效（10分）

| 绩效维度 | 信息系统的作用 | 例证 |
|---------|--------------|------|
| **需求预测精度** | POS收银机采集销售信息 → 门店计算机分析各品类销售速度 | "门店经理调看门店计算机中的数据，根据各品类销售表现下达订单" |
| **库存可见性** | 手持条码扫描仪盘点库存 → 发现损耗，"当前库存≠期初库存-销量" | 准确掌握真实库存水平，避免缺货或积压 |
| **补货效率** | 手持图形化订货终端 → 商品布局与货架相同，边巡视边下单 | "门店面积150m²小于同类，但日销售额是后者两倍" |
| **供应链协调** | 订单同时发送供应商+DC → 消除信息延迟 | 供应商实时获取所有门店订单，按需生产 |
| **品类管理** | 计算机分析"销售贡献率、顾客流量" | 减少或不订滞销品，优化3000/5000品种组合 |
| **响应速度** | 全链路信息实时传递 → POS→门店→供应商→DC | 晚餐订单→上午10点前下达→当日配送到店 |
| **降低牛鞭效应** | 需求信息直达供应商 → 减少逐层放大 | 供应商直接接收10615家门店的真实订单 |

---

> **答题思路总结**：响应性 → 找"快"的线索（频次、速度、实时）；效率性 → 找"省"的线索（合并、批量、信任）；信息系统 → 找"数据"的线索（采集、分析、传递、共享）
