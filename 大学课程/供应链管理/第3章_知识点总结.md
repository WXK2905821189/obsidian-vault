# 第3章 分销网络设计的决策过程和决策模型 —— 知识点总结

> 依据：第3章PPT | 含全部知识点

---

## 一、分销网络设计的四阶段决策框架

| 阶段 | 决策内容 | 要点 |
|------|---------|------|
| **第Ⅰ阶段** | 确定网络设计战略 | 明确目标市场、服务水平定位 |
| **第Ⅱ阶段** | 确定区域设施配置 | 决定每个区域建多少个设施 |
| **第Ⅲ阶段** | 在每个区域内选择潜在设施位置 | 考虑基础设施、劳动力、供应商等 |
| **第Ⅳ阶段** | 具体设施位置选择（使用决策模型） | 在备选地点中精准选址 |

---

## 二、选址需考虑的因素

| 因素类别 | 具体内容 |
|---------|---------|
| **基础设施** | 运输设施、通讯设施、电力设施 |
| **劳动力** | 劳动力素质、劳动力流动性 |
| **供应商** | 当地是否有供应商 |
| **社区** | 社区接纳程度 |
| **顾客** | 顾客对响应时间的要求 |
| **税收政策** | 税收优惠、进口关税 |
| **竞争环境** | 同业集聚（正外部性）vs 远离竞争对手 |
| **政治因素** | 政局稳定、贸易壁垒、汇率风险 |
| **需求风险** | 目标市场需求波动大→设施应能生产可销往其他地区的产品 |

## 三、设施选址和能力决策模型（第Ⅳ阶段）

### 3.1 问题描述（SunOil案例）

- 5个备选厂址（A-E），每个可选低产能（10百万）或高产能（20百万）
- 5个目标市场（北美、南美、欧洲、亚洲、非洲）
- 已知：各单位可变成本、固定成本、各市场需求量
- 目标：总成本最小（固定+可变）

### 3.2 数学模型（MILP）

**决策变量**：
- y_i ∈ {0,1}：是否建厂
- x_ij ≥ 0：从工厂i到市场j的供货量

**目标**：Min Z = Σ固定成本 + ΣΣ可变成本×x_ij

**约束**：
- 需求满足：Σ_i x_ij = D_j（每个市场）
- 产能限制：Σ_j x_ij ≤ K_i·y_i（每个工厂）
- 非负和整数

### 3.3 求解方法

候选厂≤5个 → **枚举法**（3^5=243种组合→筛出可行→各算运输子问题→比较）

运输子问题用**最小成本法+MODI检验**求解。

## 关键公式与概念速记

| 概念 | 核心要点 |
|------|---------|
| 四阶段框架 | 战略→区域→潜在地点→具体选址 |
| 选址因素 | 基础设施、劳动力、供应商、税收、竞争、政治 |
| 决策模型 | MILP：0-1选址+连续运输量+总成本最小 |
| 求解方法 | 枚举法（小规模）+ 运输子问题（最小成本法） |
