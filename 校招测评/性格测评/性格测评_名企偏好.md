# 性格测评·名企偏好 — 不同公司喜欢什么样的人

> [!abstract] 为什么要看名企偏好
> 不同公司的企业文化差异巨大，性格测评的筛选标准也不同。==了解目标公司的偏好，你可以在真实的基础上微调策略==，而不是用一个「通用好人」的形象去应付所有公司。

---

## 一、互联网大厂

### 字节跳动

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | ==高== | 「始终创业」文化，需要拥抱变化 |
| 尽责性 | 中高 | 需要执行力，但不喜欢过于僵化 |
| 外向性 | 中等 | 不一味追求外向，偏内向也可以 |
| 宜人性 | 中低 | 「坦诚清晰」文化，不怕冲突 |
| 情绪稳定性 | 高 | 高速迭代，抗压能力必须强 |

> [!tip] 字节关键词：快速学习、拥抱变化、坦诚直接、结果导向

### 阿里巴巴

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中高 | 需要创新，但也要执行力 |
| 尽责性 | ==高== | 「今天最好的表现是明天最低的要求」 |
| 外向性 | 中高 | 需要跨部门协作和推动 |
| 宜人性 | 中等 | 注重团队合作，但不一味迎合 |
| 情绪稳定性 | 高 | 高压环境，情绪稳定是基础 |

> [!tip] 阿里关键词：要性、皮实、乐观、自省

### 腾讯

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中高 | 产品驱动，需要创新思维 |
| 尽责性 | 中高 | 注重细节和品质 |
| 外向性 | 中等 | 技术岗偏内向也可以 |
| 宜人性 | 中高 | 「用户为本」，需要同理心 |
| 情绪稳定性 | 中高 | 相对其他大厂压力略低，但仍需稳定 |

> [!tip] 腾讯关键词：用户导向、产品思维、团队协作、长期主义

### 美团

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中等 | 重执行多于创新 |
| 尽责性 | ==高== | 「苦练基本功」，执行力为王 |
| 外向性 | 中等 | 无所谓 |
| 宜人性 | 中低 | 内部竞争激烈，不怕冲突 |
| 情绪稳定性 | ==高== | 高强度工作，抗压是刚需 |

> [!tip] 美团关键词：执行力、务实、长期有耐心

### 拼多多

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中等 | 重执行和效率 |
| 尽责性 | ==高== | 高强度、快节奏 |
| 外向性 | 无所谓 | 不看重 |
| 宜人性 | 中低 | 狼性文化，结果导向 |
| 情绪稳定性 | ==非常高== | 公认压力最大的互联网公司之一 |

## 二、外企

### 四大（普华永道、德勤、安永、毕马威）

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中低 | 审计/咨询有严格流程，不需要太多创意 |
| 尽责性 | ==非常高== | 细节决定成败，一个数字都不能错 |
| 外向性 | 中高 | 需要和客户沟通，咨询岗尤其重要 |
| 宜人性 | 中高 | 团队合作 + 客户服务 |
| 情绪稳定性 | 高 | 忙季工作强度极大 |

> [!tip] 四大关键词：专业、细节、抗压、团队合作

### 宝洁/联合利华（快消）

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中高 | 需要创新思维做营销 |
| 尽责性 | 高 | 管理培训生要求高 |
| 外向性 | 高 | 需要领导力和跨部门沟通 |
| 宜人性 | 中高 | 团队协作 |
| 情绪稳定性 | 高 | 快节奏，多项目并行 |

> [!tip] 快消关键词：领导力、创新、沟通、执行力

### 微软/Google（科技外企）

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 高 | 创新文化，鼓励探索 |
| 尽责性 | 中高 | 需要自律但不死板 |
| 外向性 | 无所谓 | 包容 introvert |
| 宜人性 | 中高 | 包容、多元的文化 |
| 情绪稳定性 | 中高 | 相对稳定，但有一定压力 |

## 三、国企/央企

### 银行（工农中建交等）

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中低 | 稳定为主，不鼓励过于冒险 |
| 尽责性 | ==非常高== | 合规、流程、细节 |
| 外向性 | 中等 | 不要求特别外向 |
| 宜人性 | 高 | 注重人际关系和谐 |
| 情绪稳定性 | 高 | 稳定压倒一切 |

> [!tip] 银行关键词：稳重、合规、细致、服从

### 三大运营商 / 能源央企

| 维度 | 偏好 | 原因 |
|---|---|---|
| 开放性 | 中低 | 流程驱动，不鼓励标新立异 |
| 尽责性 | 高 | 执行力强、遵守规则 |
| 外向性 | 无所谓 | 无明确偏好 |
| 宜人性 | 高 | 团队和谐、服从安排 |
| 情绪稳定性 | 高 | 稳定、不激进 |

> [!tip] 央企关键词：稳重、踏实、服从、团队

## 六、一句话总结

> [!tip] 名企偏好 = 企业文化的外显
> 互联网看重「创新+抗压」，国企看重「稳重+服从」，外企看重「专业+协作」。==先研究目标公司的文化，再调整答题策略。==
