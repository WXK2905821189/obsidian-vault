## 四、备战三步法

> 参考自知乎高赞回答《如何破解校招在线测评？》，系统化的备考流程。

### 第一步：查询目标公司，选择常用平台

1. 确定目标公司使用的测评平台（北森/智鼎/赛码/牛客/ATA/易考等）
2. 了解该平台题型分布和难度
3. 针对性准备，不盲目刷题

### 第二步：分类刷题，逐一熟悉题型

**错误做法**：混合刷题，行测所有题型混在一起练 → 摸不到重点，提升慢

**正确做法**：

| 阶段 | 操作 | 时长建议 |
|------|------|---------|
| 专项突破期 | 逐个题型攻克，先学方法再刷题 | 每个题型 2-3 天 |
| 专项巩固期 | 针对弱项重点加练 | 每天 1-2 小时 |
| 混合练习期 | 模拟真实考试，混合题型计时练 | 考前 1 周开始 |

### 第三步：整理错题，总结技巧/知识点

```
错题本模板：
┌─────────────────────────────────────────┐
│ 题号：XX   │  题型：图形推理/数量关系...  │
├─────────────────────────────────────────┤
│ 题目：...                                  │
│ 我的答案：A   │  正确答案：C               │
├─────────────────────────────────────────┤
│ 错误原因：□ 公式记错  □ 方法用错            │
│          □ 看错题   □ 算错                │
├─────────────────────────────────────────┤
│ 正确解法：...                              │
│ 新知识点：...                              │
└─────────────────────────────────────────┘
```

定期复习错题本，有节奏地刷新题，才能不断巩固提升。
