## 一、先搞清楚：你要装什么？

| 项目类型 | 需要装什么 | 一句话解释 |
|---|---|---|
| 网页/前端项目 | Node.js | 让你能运行 `npm` 命令 |
| Python 项目 | Python | 让你能运行 `.py` 文件 |
| 桌面应用 | Node.js | 大部分基于 Electron |

> [!tip] 90% 的 Vibe Coder 只需要装 Node.js。

---

## 二、Node.js 安装（最常用）

### 2.1 Windows 安装

**第 1 步：下载**

1. 打开 [nodejs.org](https://nodejs.org)
2. 点击左边的 **LTS**（长期支持版）按钮
3. 下载 `.msi` 安装包

**第 2 步：安装**

1. 双击下载的 `.msi` 文件
2. 一路点 Next → 勾选「Add to PATH」→ Install
3. 完成

**第 3 步：验证**

```bash
# 打开终端（Win+R → 输入 cmd → 回车）
node -v    # 应该显示版本号，如 v20.10.0
npm -v     # 应该显示版本号，如 10.2.3
```

### 2.2 Mac 安装

```bash
# 方法 1：官网下载（同 Windows）
# 方法 2：用 Homebrew
brew install node
```

### 2.3 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `'node' 不是内部或外部命令` | 没勾选「Add to PATH」 | 重新安装，确保勾选 |
| `npm -v` 显示版本但 `node -v` 不显示 | 安装不完整 | 重新安装 |
| 安装后终端还是说找不到 | 需要重启终端 | 关掉终端重新打开 |
| 想装特定版本 | 下载时选了非 LTS | 下载 LTS 版本 |

## 三、Python 安装（如果你的项目需要）

### 3.1 Windows 安装

**第 1 步：下载**

1. 打开 [python.org](https://python.org)
2. 点击 Downloads → 下载最新版

**第 2 步：安装**

1. ==勾选「Add Python to PATH」==（最重要！）
2. 点 Install Now
3. 完成

**第 3 步：验证**

```bash
python --version    # 应该显示 Python 3.x.x
pip --version       # 应该显示 pip 版本
```

### 3.2 常见问题

| 问题 | 解决 |
|---|---|
| `'python' 不是内部或外部命令` | 重新安装，勾选 Add to PATH |
| 装了多个 Python 版本 | 让 AI 帮你管理：「帮我设置默认 Python 版本」 |
| `pip install` 很慢 | 换国内镜像：「帮我配置 pip 国内镜像源」 |

## 四、什么是「环境变量 PATH」？

> [!note]- 零基础理解
> PATH 就是电脑的「地址簿」。你装了 Node.js，但电脑不知道它在哪，所以输入 `node` 报错。加了 PATH 之后，电脑就知道「哦，node 在 C:\Program Files\nodejs 里」。

安装时勾选 **Add to PATH** 就是自动帮你把地址写进地址簿。==以后装任何开发工具，看到「Add to PATH」就勾上。==
