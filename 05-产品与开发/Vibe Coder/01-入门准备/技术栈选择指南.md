# 技术栈选择指南 — 零基础怎么选 React/Vue/其他

> [!abstract] 这篇解决什么问题
> AI 问「你要用 React 还是 Vue？Vite 还是 Webpack？」你一脸懵。这篇告诉你 ==不同场景下怎么选，以及最重要的原则：让 AI 帮你选。==
>
> 前置阅读：[[05-产品与开发/Vibe Coder/Vibe Coder 常见问题全景图#1.2 不知道选什么技术栈]]

---

## 一、最重要的原则：让 AI 帮你选

> [!important] 你是产品经理，AI 是工程师
> 你不需要知道「用什么技术」，只需要描述「要做什么产品」。让 AI 推荐方案，你来选。

```
"我要做一个 [产品描述]，你推荐用什么技术栈？
给我 2-3 个方案，说明优缺点，我来选。"
```

---

## 二、零基础快速对照表

| 你的项目 | 推荐技术栈 | 一句话理由 |
|---|---|---|
| 简单网页/个人博客 | HTML + CSS + JS（或 Astro） | 最纯粹，概念最少 |
| 单页面应用 | Vite + React | 生态最大，AI 生成质量最高 |
| 追求上手速度 | Vite + Vue | 模板语法更直觉 |
| 需要后端 + 数据库 | Next.js | 前后端一体，一个框架搞定 |
| 纯后端 API | Node.js + Express | 最简单，和前端同语言 |
| 桌面应用 | Electron + React/Vue | 跨平台，一套代码出 exe |
| 移动端 App | React Native / Flutter | 移动端跨平台 |

---

## 三、React vs Vue：怎么选？

| 维度 | React | Vue |
|---|---|---|
| 学习曲线 | 稍陡（JSX 语法需要适应） | 更平缓（模板语法接近 HTML） |
| AI 生成质量 | 最高（训练数据最多） | 很高 |
| 生态/社区 | 最大 | 很大 |
| 国内使用率 | 高（大厂为主） | 高（中小企业为主） |
| 适合什么项目 | 复杂应用、长期维护 | 快速原型、中小项目 |

> [!tip] 如果完全没概念，==选 React==。因为 AI 训练数据中 React 代码最多，生成质量最高。你不需要写 React 代码，只需要让 AI 写。

---

## 四、Vite vs Webpack vs 其他构建工具

| 工具 | 是什么 | 你需要关心吗 |
|---|---|---|
| Vite | 新一代构建工具，快 | ==不需要==，让 AI 选 |
| Webpack | 老牌构建工具，配置复杂 | 不需要 |
| CRA | React 官方脚手架 | 逐渐被 Vite 取代 |

> [!tip] 对 AI 说「用 Vite 创建项目」就行，不需要理解这些工具的区别。

---

## 五、Tailwind CSS vs 纯 CSS vs 组件库

| 方案 | 适合场景 | 优缺点 |
|---|---|---|
| Tailwind CSS | 追求开发效率和一致性 | AI 写 Tailwind 最快，但 class 很长 |
| 纯 CSS | 完全自定义样式 | 灵活但 AI 写起来稍慢 |
| 组件库（Ant Design 等） | 后台管理系统 | 开箱即用，但样式固定 |

> [!tip] 建议用 Tailwind CSS——AI 写 Tailwind 类名又快又准，生成的 UI 也好看。

---

## 六、数据库选型：什么时候需要？

| 你的需求 | 方案 | 复杂度 |
|---|---|---|
| 不需要存数据 | 不需要数据库 | ⭐ |
| 少量数据，个人用 | JSON 文件存储 | ⭐ |
| 需要用户系统、多用户 | SQLite（本地）或 Supabase（云端） | ⭐⭐ |
| 复杂业务逻辑 | PostgreSQL + Prisma | ⭐⭐⭐ |

> [!tip] 对 Vibe Coder 来说，==先用 JSON 文件存数据，等真的需要数据库了再升级。==

## 七、典型场景推荐

### 场景 1：个人博客

```
推荐：Astro + Markdown
部署：GitHub Pages 或 Vercel
为什么：最纯粹，Markdown 写文章，自动生成静态页面
```

### 场景 2：记账/待办/工具类 Web 应用

```
推荐：Vite + React + Tailwind CSS
数据存储：localStorage 或 JSON 文件
部署：Vercel
为什么：AI 最擅长这套组合，生成质量最高
```

### 场景 3：需要用户系统的 SaaS 产品

```
推荐：Next.js + Supabase
部署：Vercel
为什么：Next.js 前后端一体，Supabase 提供免费数据库和认证
```

### 场景 4：桌面工具

```
推荐：Electron + React + Vite
打包：electron-builder
为什么：一套代码出 Windows/Mac 应用
```
