# 基地建设的项目分类体系操作指南

> **实操性最强的方法论文档**（约16,700字），将战略规划落地为可执行的项目编制模板。

---

## 项目分类总览

基地建设涉及七大类项目，本文档详述前四类：

| 项目类型 | 核心目标 | 与修理的关键区别 |
|----------|----------|:---------------:|
| **技术改造（技改）** | 升级与增强 | ❗必须严格区分 |
| **修理** | 修复缺陷与维持运转 | 区分错误 = 合规风险 |
| **小型基建** | 新建/扩建物理空间 | |
| **网络建设** | 信息化/数智化平台 | |

## 每类项目的五步编制指南

```mermaid
    A["是什么<br/>定义概念"] --> B["包含什么<br/>内容范围"]

```

### 1. 技术改造项目

- **核心目标**：升级设备性能、引入新技术、提升培训效果
- **命名模板**：`单位 + 对象 + 行为`（如"XX供电局变电仿真实训室技术改造"）
- **必要性论证**：采用"问题-影响-价值"黄金圈法则
- **关键决策字段**：投资估算、合规准入、优选级别、紧迫性判断

### 2. 修理项目

- **核心目标**：修复设备缺陷、维持正常运转
- 与技改的核心区别：修理是**恢复**原功能，技改是**增强**功能
- 严格区分是项目合规性的关键

### 3. 小型基建项目

- 含场地新建、扩建、功能改造
- 遵循基建项目审批流程
- 关注土地、规划许可等前置条件

### 4. 网络建设项目

- 信息化平台、数智化系统建设
- 网络安全合规要求
- 与现有系统的兼容性评估
