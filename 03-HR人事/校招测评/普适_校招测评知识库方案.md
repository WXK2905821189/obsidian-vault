# 校招测评不挂科 — 用 Obsidian 建一个自己的上岸题库 📚

> 校招季最崩溃的瞬间：
> 刚被行测刷掉，下一家还要从头找资料。
> 上次面试被问爆的题忘了记，这次又被问同一个。
>
> **建一个自己的知识库，一次整理，整个秋招都在用。**

---

## 校招到底要过多少关？🤯

```
投简历 → 在线笔试 → AI面试 → 群面 → 专业面 → 终面 → offer
         ↑ 60%的人挂在这  ↑ 50%的人挂在这
```

每一关考的东西完全不一样。但好消息是——**考的套路是固定的。**

```
行测      →  判断推理 + 资料分析 + 言语理解 + 数量关系 + 常识
性格测评  →  测谎题 + 企业偏好匹配
AI面试    →  行为题（宝洁八大问变体） + 情景题 + 自我介绍
群面      →  角色扮演 + 案例分析 + 小组讨论
专业笔试  →  分岗位：产品题 / 技术题 / 运营题
```

> 💡 每一类题都有固定的套路和解题模板。
> **你要做的不是刷一万道题，是把每一类的套路整理清楚。**

---

## 知识库长什么样？🗂️

用 Obsidian 建，免费，笔记之间可以互相链接，像自己的维基百科。

```
校招测评/
│
├── 📁 行测/               ← 笔试第一关
│   ├── 判断推理（提分最快）
│   ├── 资料分析（送分最多）
│   ├── 言语理解（语感为主）
│   ├── 数量关系（时间不够先跳过）
│   └── 常识判断（随缘）
│
├── 📁 AI面试/             ← 对着摄像头说话
│   ├── AI怎么给你打分的？
│   ├── 行为题万能模板
│   ├── 情景题万能模板
│   └── 30道高频题 + 参考答案框架
│
├── 📁 群面/               ← 一群人抢着说话
│   ├── 四种角色怎么选
│   ├── 发言模板（开场/总结/推进）
│   └── 10个经典案例
│
├── 📁 性格测评/           ← 最容易被忽略的淘汰关
│   ├── 测谎题长什么样？
│   └── 不同公司喜欢什么性格？
│
├── 📁 名企题库/           ← 按公司找
│   ├── 字节、腾讯、阿里…
│   └── 每家的流程 + 真题回忆
│
└── 📁 备战体系/           ← 时间不够用的救星
    ├── 7天冲刺计划
    └── 30天系统准备计划
```

## 每篇笔记怎么写？（模板直接套）

打开任何一个题型笔记，按这个结构写：

```
1. 📊 考情速览
   这题每年考几次？限时多久？多少道？

2. 🧠 解题套路（最重要）
   不是例题堆砌，是先讲方法。
   「看到 XX 题型 → 先想 XX → 再用 XX 技巧」

3. 📝 经典例题 × 5
   每道题有一句话的核心思路标注

4. ⚡ 速杀技巧
   行测是限时的，会技巧比会做重要

5. 🕳️ 常见陷阱
   80%的人会踩的坑

6. 🔗 推荐练习资源
```

## 分阶段建设计划 🏗️

不用一口气做完，按时间优先级来：

### 🥇 第一波：行测（最快提分）

**判断推理 → 资料分析 → 言语理解 → 数量关系 → 常识判断**

> 判断推理最容易套公式提分，资料分析分数最稳，常识判断放最后——投入产出比太低。

### 🥈 第二波：AI 面试

**评分逻辑 → 行为题模板 → 情景题模板 → 高频题库**

> AI 面试的核心不是「感人」，是「结构清晰 + 关键词覆盖」。搞清楚 AI 怎么打分，你就知道该说什么。

### 🥉 第三波：群面 + 性格测评

**角色策略 → 发言框架 → 经典案例 → 性格避坑**

### 🏅 第四波：名企题库

**按你投的公司顺序来建，投一家建一家。**

## 实际怎么用？📱

| 阶段 | 打开什么 |
|---|---|
| 收到笔试通知 | 打开 `行测/` 文件夹，看对应题型的「解题套路」和「速杀技巧」 |
| 笔试前 30 分钟 | 扫一遍「常见陷阱」 |
| 收到 AI 面试通知 | 打开 `AI面试/`，对着「高频题库」练 3 遍 |
| 群面前一天 | 打开 `群面/`，决定你明天要扮演什么角色，准备好话术 |
| 性格测评前 | 看「避坑指南」——测谎题怎么应对，虚假作答是什么样 |

---

## 和市面上的题海有什么不同？🆚

| 题海战术 | 这个知识库 |
|---|---|
| 刷 1000 道题 | 先搞清每类题的套路，再精选 20 道练 |
| 练完就忘 | Obsidian 笔记永久留存，秋招全程复用 |
| 各个公司资料散落 | 按公司索引，一键找到 |
| 被刷了不知道为什么 | 「常见陷阱」告诉你为什么挂 |

---

> 🎯 **这个知识库的本质：**
> 不是给你一万道题——那是题海。
> 是给你一张地图，告诉你在每个关卡，考官想测什么、套路是什么、你怎么准备。
