# 备战·模拟与复盘 — 模考正确姿势 + 错题复盘方法论

> [!abstract] 为什么刷了 100 套题还是没进步
> 因为 ==只刷题不复盘 = 把错误重复了 100 遍==。模拟考试的目的不是「检验水平」，而是「发现薄弱点」。复盘才是真正让你进步的那一步。

---

## 一、模拟考试的正确姿势

### 1.1 模考频率

| 阶段 | 频率 | 目的 |
|---|---|---|
| 基础期 | 每周 1 次 | 了解题型，建立节奏 |
| 强化期 | 每周 2-3 次 | 发现问题，针对性补强 |
| 冲刺期 | 每周 3-4 次 | 保持手感，提升速度 |

### 1.2 模考环境

> [!important] 模拟越真实，考场越轻松

| 条件 | 要求 |
|---|---|
| 时间 | 严格限时，到点停笔 |
| 环境 | 安静，不受打扰 |
| 设备 | 用考试时用的电脑/手机 |
| 心态 | 当成正式考试，不做任何额外操作 |

### 1.3 模考流程

```mermaid
flowchart LR
    A[模考前<br/>清空桌面] --> B[严格限时<br/>做完整套题]
    B --> C[对答案<br/>统计正确率]
    C --> D[分类错题<br/>找原因]
    D --> E[针对性补强<br/>同类题再练]
    E --> F[记录进步<br/>更新数据]
```

## 二、错题复盘方法论

### 2.1 错题分类

每道错题归结为以下 5 类之一：

| 错误类型 | 表现 | 对策 |
|---|---|---|
| **知识盲区** | 公式不会、概念不懂 | 回看笔记，重新学习，做 5 道同类题 |
| **方法错误** | 用的方法不对，导致算错或超时 | 学习正确方法，做 3 道同类题 |
| **审题不清** | 看错时间/单位/概念 | 下次做题前先圈关键词 |
| **计算失误** | 方法对但算错了 | 速算练习加量 |
| **时间不够** | 会做但没时间做 | 调整做题顺序，提升速度 |

### 2.2 错题记录模板

```
【错题编号】：2026-07-23-01
【题型】：资料分析 - 基期量计算
【错误类型】：审题不清
【错误原因】：材料给的是 2023 年数据，题目问的是 2022 年，我直接用了 2023 年数据
【正确做法】：先圈出「2022 年」，再找对应数据
【同类题训练】：已做 3 道基期量计算，全对 ✓
```

### 2.3 错题复习节奏

| 时间 | 操作 |
|---|---|
| 当天 | 分类记录，分析原因 |
| 第 2 天 | 做同类题 3-5 道 |
| 第 7 天 | 重新看一遍错题，确认已经掌握 |
| 第 14 天 | 快速过一遍，确认不会再错 |

## 三、AI 面试模拟

### 3.1 模拟工具

| 工具 | 说明 |
|---|---|
| 牛客网 AI 面试 | 模拟真实 AI 面试，有评分和反馈 |
| 赛码 AI 面试 | 同上 |
| 自己录制 | 用手机录视频，回看自己的表现 |
| 找朋友模拟 | 让朋友当面试官，给你出题 |

### 3.2 模拟检查清单

| 检查项 | 标准 |
|---|---|
| 时长 | 每题 60-90 秒 |
| 结构 | 有 STAR/CLAIM 框架 |
| 摄像头 | 看摄像头，不是看屏幕 |
| 表情 | 自然微笑，适度点头 |
| 语速 | 适中，每分钟 180-220 字 |
| 填充词 | 尽量少用「嗯」「那个」「就是」 |
| 关键词 | 是否植入了岗位关键词 |

### 3.3 模拟复盘

每次模拟后，回答以下问题：

1. 哪道题回答得最好？为什么？
2. 哪道题回答得最差？为什么？
3. 有没有超时或卡顿？
4. 表情和眼神是否自然？
5. 下次需要改进什么？

## 五、一句话总结

> [!tip] 刷题不改错 = 白刷
> ==模考 → 分类错题 → 找原因 → 针对性补强 → 再模考验证。== 每次模考都要比上一次进步一点点。
