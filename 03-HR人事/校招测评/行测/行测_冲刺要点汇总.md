# 行测冲刺要点汇总 — 公式·方法·策略

> 本文整合自知乎高赞文章《行测冲刺要点全梳理》，涵盖各模块的核心公式、解题方法、考场策略，适合考前冲刺阶段快速翻阅。
>
> 参考来源：[行测冲刺要点全梳理](https://zhuanlan.zhihu.com/p/608829334)

---

## 考场策略总则

| 模块 | 做题顺序建议 | 时间分配 | 策略 |
|------|------------|---------|------|
| 常识判断 | 最前或最后 | 5-8 分钟 | 靠"浅意识"解题，不要深思，避免浪费时间 |
| 言语理解 | 精力最集中时 | 15-20 分钟 | 选词填空不纠结，越纠结越错 |
| 判断推理 | 精力最集中时 | 15-20 分钟 | 图形推理一眼扫过不会就放弃，后续再看 |
| 资料分析 | 靠前的时间点 | 15-20 分钟 | 题目简单、题量大，作为重点拿分模块 |
| 数量关系 | 靠后的位置 | 10-15 分钟 | 选择性突破，做擅长的题型，其他蒙 |

## 一、常识判断

### 冲刺要点

- 利用**碎片化时间**重点关注时事政治
- 重点推荐内容：**党的二十大报告、当地政府工作报告、上一年各领域所取得的重大突破**
- 考试策略：放在最前或最后来做，**靠"浅意识"解题**，不要深思

### 备考建议

| 资源 | 用途 | 频率 |
|------|------|------|
| 学习强国 APP | 时政新闻 | 每天 10 分钟 |
| 人民日报 APP | 时政要闻 | 每天 5 分钟 |
| 粉笔 APP「常识判断」 | 刷常识题 | 每天 20 题 |

## 二、言语理解与表达

### 模块概览

| 题型 | 难度 | 题量占比 | 备考策略 |
|------|------|---------|---------|
| 选词填空 | 较大 | ~40% | 先分析语境，再辨析词语，不纠结 |
| 片段阅读 | 较低 | ~40% | **重点突破判断意图**，性价比最高 |
| 语句表达 | 中等 | ~20% | 句子排序+填空，准确率相对较低 |

### 选词填空

#### 语境分析四关系

| 关系类型 | 标志词 | 示例 |
|---------|--------|------|
| **相反相对** | 但是、然而、却、其实、实际上 | "融入智能生活的老年人越来越多了，**但是**专门面向老年人开发的产品____" → 填"少" |
| **并举** | 和、与、同、也、同样 | "既要……也要……" |
| **递进** | 甚至、更、尤其、特别是 | 程度逐层加深 |
| **解释说明** | 即、也就是说、比如、例如、冒号、破折号 | 前后文直接解释 |

#### 词义辨析六角度

| 角度 | 说明 | 示例 |
|------|------|------|
| 含义侧重 | 词语的核心意思差异 | "成果"vs"后果"（褒贬不同） |
| 语义轻重 | 程度差异 | "批评"vs"批判" |
| 感情色彩 | 褒义/贬义/中性 | "鼓励"vs"煽动" |
| 搭配对象 | 与什么词搭配 | "提高"搭配水平，"增强"搭配能力 |
| 适用范围 | 适用对象范围大小 | "时代"vs"时期" |
| 词性和句法功能 | 动词/名词/形容词 | "突然"vs"猛然"（副/副+动） |

### 片段阅读

**核心题型：判断意图（主旨概括）**

```
解题步骤：
1. 通读全文，抓关键句（转折词后、总结词后、观点词后）
2. 整合关键句，确认主旨
3. 排除干扰项（片面/过度推断/无中生有）
```

**常见标志词**：
- 转折：但是、然而、却、实际上
- 总结：因此、所以、由此可见
- 观点：认为、应该、需要、建议

### 语句表达

| 题型 | 解题方法 |
|------|---------|
| 句子排序 | ①看首句（排除不适合做首句的选项）②找捆绑（关联词/指代词/顺序词）③验证 |
| 句子填空 | ①看位置（首句→总起，中间→承上启下，尾句→总结）②看逻辑关系 |

## 三、数量关系

### 冲刺策略

> **选择性突破**：数量关系难度大，全部做对不现实。建议选 3-4 种最擅长的题型重点突破，考试时只做这几类，其他蒙。

### 高频题型速览

| 题型 | 难度 | 推荐程度 | 核心方法 |
|------|------|---------|---------|
| 计算问题 | ⭐⭐ | ⭐⭐⭐⭐⭐ | 方程法、等差数列、整除特性 |
| 工程问题 | ⭐⭐ | ⭐⭐⭐⭐⭐ | 特值法（设总量/效率/时间） |
| 年龄问题 | ⭐⭐ | ⭐⭐⭐⭐ | 代入排除、列表列方程 |
| 和定最值 | ⭐⭐⭐ | ⭐⭐⭐⭐ | 列表分析，求某量最大/最小 |
| 行程问题 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 画图+公式 |
| 排列组合与概率 | ⭐⭐⭐⭐ | ⭐⭐⭐ | 分类/分步，正难则反 |
| 几何问题 | ⭐⭐⭐ | ⭐⭐⭐ | 公式+割补 |

### 核心公式与方法

#### 1. 计算问题

**方程法**：构造等量关系
- 标志词：是、等、共、占、相当于、比…多/少、倍
- 无明显标志词时，结合基本数量关系构造

**等差数列**：

$$a_n = a_1 + (n-1)d$$

$$S_n = \frac{(a_1 + a_n)n}{2} = na_1 + \frac{n(n-1)d}{2}$$

**整除特性**：
- 文字描述出现"整除、平均、每、倍"等字眼
- 题干出现"分数、百分数、比例"等特征数据

#### 2. 工程问题（合作问题）

| 条件 | 特值设法 | 适用场景 |
|------|---------|---------|
| 已知多个主体完工时间 | 设工作总量为 1 或完工时间的公倍数 | 最常见 |
| 已知多个主体效率关系 | 将效率最简比设为份数 | 效率比明确 |
| 已知多个主体效率相同 | 设每个主体的效率为 1 | 多人合作 |

#### 3. 和定最值（极值问题）

**特征**：几个量的和一定，求其中某个量的最大或最小。

**解题原则**：
- 求某量最大 → 其他量尽可能小
- 求某量最小 → 其他量尽可能大

**步骤**：列表分析 → 设未知数 → 列等式求解

#### 4. 年龄问题

**核心原则**：
- 年龄差不变
- 年龄同增减

**方法**：代入排除最快，复杂时列表列方程

## 四、判断推理

### 模块概览

| 题型 | 题量 | 难度 | 策略 |
|------|------|------|------|
| 图形推理 | 5-10 题 | 中等 | 按流程试规律，不会就先放弃 |
| 定义判断 | 5-10 题 | 较低 | 读定义要点，带选项比对 |
| 类比推理 | 5-10 题 | 低 | 注意词项间关系，半分钟一题 |
| 逻辑判断 | 10 题 | 中等 | 性价比高，学习后快速提分 |

### 图形推理

**破题总思路**：

```
图形相似（外部轮廓相同，内部填充不同）→ 样式规律（叠加/遍历）
图形相异（外部轮廓不同）→ 先属性（对称/曲直/封闭/角）
                       → 属性无规律 → 数数量（点/线/面/素/笔画数）
```

详见 [[03-HR人事/校招测评/题库/行测_图形推理_题库]] 的破题流程图和速查卡。

### 定义判断

**方法**：读定义要点 → 带选项比对

**常见要点**：
- 主体、客体
- 条件（前提/方式/目的）
- 结果（影响/效果）

### 类比推理

**常见词项关系**：

| 关系类型 | 示例 |
|---------|------|
| 并列关系 | 苹果∶香蕉 |
| 包容关系 | 水果∶苹果 |
| 对应关系 | 医生∶医院 |
| 语法关系 | 跑步∶锻炼 |
| 象征关系 | 玫瑰∶爱情 |

### 逻辑判断

#### 必然性推理

**命题对当关系**：

| 命题类型 | 典型形式 | 矛盾命题 |
|---------|---------|---------|
| 直言命题 | 所有A是B / 有些A不是B | 所有A是B ↔ 有些A不是B |
| 联言命题 | A且B | 非A或非B |
| 选言命题 | A或B | 非A且非B |
| 假言命题 | 如果A则B | A且非B |

**矛盾法三步走**：
```
一找：找到矛盾，确定真假话所在范围
二绕：绕开矛盾，先分析已确定真假的条件
三返回：返回矛盾，分析矛盾的具体真假
```

**常见假言命题形式**：
- 如果 A，那么 B → A→B
- 只有 A，才 B → B→A
- 除非 A，否则不 B → B→A
- 只要 A，就 B → A→B

#### 可能性推理

**核心题型**：加强型、削弱型

**解题思路**：找出题干中的**因果关系**，再对因果进行加强或削弱。

**常见因果联结词**：导致、引起、造成、原因、由于

| 类型 | 加强方法 | 削弱方法 |
|------|---------|---------|
| 因果 | 排除他因、无因无果、有因有果 | 另有他因、因果倒置、有因无果 |
| 类比 | 相似性更强 | 相似性弱、本质差异 |
| 举例 | 补充更多例证 | 反例、样本不具代表性 |

## 五、资料分析

> **资料分析是行测中性价比最高的模块**——公式固定、方法套路化，通过系统训练短期内即可大幅提分。

### 常用公式

#### 单一数据

| 公式 | 表达式 |
|------|--------|
| 基期值 | $基期 = \frac{现期}{1+增长率}$ |
| 增长量 | $增长量 = 现期 - 基期 = 现期 \times \frac{增长率}{1+增长率}$ |
| 增长率 | $增长率 = \frac{现期 - 基期}{基期} \times 100\%$ |

#### 两数之比（倍数/比重/平均数通用）

$两数之比 = \frac{A}{B}$

| 指标 | A | B |
|------|---|----|
| 比重 | 部分值 | 整体值 |
| 倍数 | 比较值 | 基准值 |
| 平均数 | 总量 | 份数 |

#### 隔年增长

$隔年增长率 = r_1 + r_2 + r_1 \times r_2$

$隔年基期 = \frac{现期}{1 + 隔年增长率}$

#### 年均增长

$年均增长量 = \frac{末期 - 初期}{n}$（n为增长次数）

### 速算方法

| 运算类型 | 方法 | 操作要点 |
|---------|------|---------|
| 加减法 | **尾数法** / 从高位开始计算 | 尾数相加看末位，高位逐位算 |
| 乘法 | **特征数字法** | 将百分数转化为分数（如 25%=1/4） |
| 除法 | **直除法** | 分子不变，分母四舍五入取三位后直接除 |
| 混合运算 | **先加减后乘除** | 按运算顺序分步计算 |

**常用分数转化表**（速算必备）：

| 百分数 | 分数 | 百分数 | 分数 |
|--------|------|--------|------|
| 50% | 1/2 | 33.3% | 1/3 |
| 25% | 1/4 | 20% | 1/5 |
| 16.7% | 1/6 | 14.3% | 1/7 |
| 12.5% | 1/8 | 11.1% | 1/9 |
| 10% | 1/10 | 9.1% | 1/11 |

## 六、考场时间分配

### 理想时间分配（总时长 90-120 分钟）

```
┌────────────────────────────────────────────────┐
│  常识判断   5-8 分钟  │  靠"浅意识"，不深思      │
├────────────────────────────────────────────────┤
│  言语理解   15-20 分钟 │  选词填空不纠结          │
├────────────────────────────────────────────────┤
│  判断推理   15-20 分钟 │  图推不会先跳过           │
├────────────────────────────────────────────────┤
│  资料分析   15-20 分钟 │  优先做，确保正确率       │
├────────────────────────────────────────────────┤
│  数量关系   10-15 分钟 │  只做擅长的，其他蒙       │
├────────────────────────────────────────────────┤
│  涂卡检查   5-10 分钟  │  预留时间涂卡+检查       │
└────────────────────────────────────────────────┘
```

### 做题顺序建议

**推荐顺序**：资料分析 → 言语理解 → 判断推理 → 常识判断 → 数量关系

**理由**：资料分析简单稳定，先做确保拿分；言语和判断推理放到精力最集中时；常识和数量关系放最后，时间不够时可以快速处理。
