## 使用指南

| 你的状态 | 打开什么 |
|---|---|
| 刚收到笔试通知，还有 3 天 | `行测/` → 看题型对应的「解题套路」和「速杀技巧」 |
| 笔试前 30 分钟 | 扫对应题型的「常见陷阱」 |
| 拿到北森测评题库，不知道从哪刷起 | `题库/` → [[03-HR人事/校招测评/题库/北森测评_题库索引]]（714 题真题，先看北森考点分布） |
| 收到 AI 面试通知 | `AI面试/` → 先看「评分逻辑」，再练「高频题库」 |
| 要做性格测评了 | `性格测评/` → 先看「避坑指南」 |
| 整个秋招还没开始准备 | `备战/` → 「时间规划」+「每日训练计划」 |
