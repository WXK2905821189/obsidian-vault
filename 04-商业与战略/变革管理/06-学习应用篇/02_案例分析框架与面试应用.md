# 案例分析框架与面试应用

> 一句话定位：把"学过的模型"变成"用得上的能力"，提供统一的案例拆解框架与面试话术模板。

## 一 案例拆解四段法

任何企业变革案例，都按四个段落拆解，案例与理论可互查：

1. **背景**：外部环境与内部状态，回答"为什么非变不可"，即紧迫感的来源
2. **变革内容**：战略、组织、业务、文化改了哪些，回答"变了什么"
3. **理论映射**：用模型解释"怎么变的"，回答"为什么这样变能成"
4. **成功要素或教训**：提炼可迁移结论，回答"换一家公司能不能学"

### 各段写作要点

- **背景段**：写外部压力与内部状态，各两到三条，指向"不变不行"
- **变革内容段**：按战略、组织、业务、文化四维列举，用动作词开头
- **理论映射段**：先讲模型步骤，再逐条对应事实，事实先行
- **启示段**：写可迁移结论，不写只适用于该公司的细节
- **数量控制**：每个案例四段合计不超过800字，面试口述控制在90秒

| 四段法 | GE | 阿里 | 驴妈妈 |
| --- | --- | --- | --- |
| 背景 | 竞争加剧、份额萎缩 | 平台模式增长见顶 | 疫情致需求归零 |
| 变革内容 | 数一数二、削层级 | 四大基建 + 组织拆分 | 4R应对、跨界求生 |
| 理论映射 | 科特八步 | 科特八步 + 勒温 | 4R + 责任型领导 |
| 成功要素 | 愿景清晰、文化锚定 | 长期主义、技术自研 | 责任权衡、快速反应 |

> [!tip] 关键洞察
> 四段法的价值是让回答有结构、有理论、有迁移。面试官听到的不是一个故事，而是一个能复用的分析能力。

## 二 任意企业变革的操作模板

面对陌生企业变革题，按三步操作：

1. **选模型**：从模型速查表选2-3个，以"科特八步定结构 + 勒温解冻讲方法 + 组织韧性衡量结果"打底，视情况换入4R、E-O
2. **套事实**：把企业公开信息填入四段法，先摆事实再套理论，避免理论空转
3. **下结论**：给出可迁移的成功要素或教训，落到"对别的公司有什么用"

模板句式：背景是……，企业选择……（变革内容），这对应……（模型）的第……步，因为……所以成功或失败，可迁移的启示是……。

### 模板示例

题目：分析某制造企业向服务化转型。选模型：科特八步 + 战略柔性。背景：行业进入存量市场，设备销售见顶。变革内容：三一重工式服务化，远程运维、智能调度。理论映射：科特八步中愿景对应智慧矿山解决方案服务商定位，授权对应数字化团队组建；战略柔性中能力柔性对应运维能力复用。启示：制造服务化的成败取决于数字化底座与组织授权。

## 三 面试中讲变革的话术结构

**STAR + 理论点睛**，四句话各配一个理论锚点：

| 环节 | 讲什么 | 理论点睛 |
| --- | --- | --- |
| 情境 Situation | 当时组织面临什么压力，为什么非变不可 | 用[[04-商业与战略/变革管理/02-变革理论篇/03_科特八步与变革失败八因|科特八步]]的紧迫感判断变革必要性 |
| 任务 Task | 你在变革中扮演什么角色 | 用科特八步定位自己的位置：推动者、执行者或桥梁 |
| 行动 Action | 你具体做了什么 | 用[[04-商业与战略/变革管理/02-变革理论篇/02_线性模型：E-O理论与勒温三阶段|勒温三阶段]]说明：如何解冻（制造紧迫、脱离旧习）、如何变革（试错、短期成功）、如何再冻结（制度固化） |
| 结果 Result | 效果如何，量化最好 | 用组织韧性衡量：只是复原还是实现超越 |

> [!tip] 关键洞察
> 面试讲变革的胜负手在理论点睛：同样一段经历，点出模型的人显得有方法论，只讲故事的人显得靠运气。点睛用一句话，不堆术语。

### 示例 一段STAR回答

情境：去年年中，公司新系统上线后一线反对声大，使用率不足三成。任务：我负责推动全员切换，充当变革执行者。行动：我先用数据点破旧系统的高成本，制造紧迫感（解冻）；再组建跨部门种子用户群，小范围试点跑通后推广（变革）；最后把新系统使用写入考核（再冻结）。结果：三个月后使用率升至85%，团队还主动提出20条优化建议。理论点睛：这不是一次命令式切换，而是一次完整的解冻、变革、再冻结。

## 四 常见面试题与答题框架

| 面试题 | 答题框架 |
| --- | --- |
| 讲一次你推动改变的经历 | STAR四段 + 科特八步定位角色 |
| 你如何看待公司转型失败 | 四段法拆解 + 科特变革失败八因对照 |
| 空降到新团队怎么开展工作 | 空降兵四阶段 + 任务冲突与关系冲突管理 |
| 如何说服抵触变革的同事 | 心理契约 + 勒温解冻三法 + 变革型领导四维度 |
| 你怎么理解变革中的领导力 | 变革领导力四要素 + 魅力型与变革型领导对比 |
| 公司变革想快怎么办 | 战略柔性 + 授权行动 + 短期成功节奏 |

## 五 与战略落地与组织变革知识库的衔接

- 本库管理论：模型怎么定义、怎么对比、案例怎么拆，学术视角
- [[04-商业与战略/战略落地与组织变革/00_MOC_战略落地与组织变革中枢|战略落地与组织变革]]管实战：解码会、变革办、一把手杠杆，落地视角
- 同一个模型两处都有入口：科特八步在本库看完整论述，在实战库看"八步变成一把手的具体动作"
- 面试实操题（你会怎么做）优先用实战库；理论题（科特八步是什么）优先用本库
- 学完本库四段法再进实战库，带着理论骨架看实战动作，理解会更深一层

## 六 追问应对技巧

- 追问"你怎么看失败"：先承认失败，再用科特失败八因定位原因，最后给出改进动作
- 追问"换一家公司怎么办"：把成功要素抽象成条件，区分可迁移与不可迁移部分
- 追问"理论太理想"：承认模型边界，补充组织现实（利益格局、文化惯性、时间约束）

## 七 自我练习清单

1. 选一段你经历过的改变，用四段法写一页纸
2. 给这段经历配两个模型，写出理论点睛句
3. 找一家近期转型的公司（阿里、三一、车企），用四段法完整拆一遍
4. 把STAR答案讲给朋友听，请他只挑"没讲理论"的地方
