# 🖥️ 终端/CLI 编程 Agent

> [!note]- 零基础读者必读
> **什么是终端/CLI**：终端就是一个黑色的命令窗口（类似黑客电影里的那种），程序员在里面打字让电脑做事。**这类工具适合谁**：愿意在黑色窗口里打字，不介意没有图形界面的用户。**你大概看到什么**：一个黑底白字的窗口，你在里面用中文告诉 AI 要做啥，AI 自动写代码、自动检查、自动修问题。

> AI 在命令窗口里自动帮你写代码——你说「我要一个记账软件」，它自己规划步骤、写代码、自动检查能不能用、发现问题自己修。

## Claude Code（Anthropic）

> [!info] 一句话
> ==最懂你代码库的 AI 工程师==——主动扫描全仓库，深度理解架构，不只是写代码，还会帮你想方案。

| 维度 | 详情 |
|---|---|
| 厂商 | Anthropic |
| 上线 | 2025 年 |
| 运行方式 | 终端 CLI + VS Code 扩展 |
| 核心模型 | Claude Sonnet / Opus 4 |
| 定价 | Max 5x：\$100/月；Max 20x：\$200/月；API 按量计费 |
| 核心能力 | CLAUDE.md 双层记忆、MCP（一种让 AI 能连接外部工具和数据源的接口标准）、Skills 可复用工作流 |
| 开源 | ✅ 开源 |

> [!tip] 关键词：深度、主动、记忆
> - 主动扫描全仓库 → 理解整体架构后再动手
> - 不只执行指令 → 主动发现你没说的问题
> - CLAUDE.md 记录偏好 → 越协作越顺手

## Codex（OpenAI）

> [!info] 一句话
> ==云端多 Agent 编程引擎==——精准执行、10 个 Agent 并行干活、网页即开即用。2026 年 7 月并入 ChatGPT。

| 维度 | 详情 |
|---|---|
| 厂商 | OpenAI |
| 上线 | 2025.5（研究预览），2026.7 并入 ChatGPT |
| 运行方式 | 网页 + CLI + VS Code + macOS 桌面 App |
| 核心模型 | GPT-5-Codex（基于 o3 系列 codex-1） |
| 定价 | Plus：\$20/月；Pro：\$200/月 |
| 核心能力 | 云端沙箱——在远程服务器上给你一个「临时实验环境」，在里面怎么折腾都不会影响你自己的电脑、10 Agent 并行、和 GitHub（程序员用来存代码和协作的在线平台）深度打通 |
| 开源 | ❌ 闭源 |

> [!tip] 关键词：精准、并行、零门槛
> - ==指令遵循极强==：让你改 CSS 绝不动 HTML
> - ==并行 10 Agent==：做界面、做后台功能、检查有没有问题、发布上线，这些活同时进行
> - ==网页即用==：无需安装，浏览器打开就能用

## Hermes Agent（Nous Research）

> [!info] 一句话
> ==开源自进化的多 Agent 框架==——越用越懂你，十几个渠道接入，最活跃的开源 Agent 项目。

| 维度 | 详情 |
|---|---|
| 厂商 | Nous Research |
| 上线 | 2026 年初，v0.11.0（2026.4.23） |
| 运行方式 | CLI + Hermes Desktop + 十几个 IM 渠道 |
| 核心模型 | 开放：支持 OpenRouter 任意模型（含免费腾讯 Hy3） |
| 定价 | 免费版 + Nous Portal 四档订阅 |
| 核心能力 | 越用越聪明（自进化）——它会记住你的习惯和偏好，每次都比上一次更顺手、MoA（混合智能体，多个 AI 同时干活，投票选最佳方案）、Profiles 专家系统、永久记忆 |
| 开源 | ✅ 开源 |

> [!tip] 关键词：自进化、免费、渠道全覆盖
> - ==越用越聪明==：记录你的偏好和习惯，每次都在进步
> - ==MoA 投票决策==：多个 Agent 一起干，减少「人工智障」
> - ==零成本可跑==：输入一行指令，就能用免费的国产 AI 模型（腾讯混元），完全不花钱。
