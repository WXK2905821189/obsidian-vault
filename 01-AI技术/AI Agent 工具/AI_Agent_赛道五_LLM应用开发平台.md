# 🏗️ LLM 应用开发平台

> 不是「用 AI」，而是「造一个 AI 工具给别人用」。比如你想做一个公司内部的智能客服机器人，或者一个能自动筛选简历的 AI 助手——这类平台让你不用写代码就能搭建出来。

> [!note]- 零基础读者必读
> **什么是 LLM**：LLM（大语言模型，Large Language Model）就是 ChatGPT、文心一言这类 AI 背后的『大脑』。**什么是 LLM 应用开发平台**：让你不用写代码，通过拖拽和配置就能自己做一个 AI 应用（比如智能客服、简历筛选助手）。**需要你会什么**：需要一点学习成本，但不需要写代码。Coze 门槛最低（零代码），Dify/n8n 灵活度更高但要稍微学一下。**你大概看到什么**：一个网页后台，左边是菜单，中间是画布（可以拖拽搭流程），右边是配置面板。

## Dify

> [!info] 一句话
> ==最受欢迎的开源 LLM 应用开发平台==——77K+ GitHub Star，像画流程图一样，用拖拽的方式设定 AI 的做事步骤——先干什么、再干什么、遇到什么问题怎么处理，从原型到生产环境一站完成。

| 维度 | 详情 |
|---|---|
| 厂商 | Dify.AI（开源社区驱动） |
| 定位 | 开源 LLM 应用开发平台 |
| 核心能力 | 像画流程图一样，用拖拽的方式设定 AI 的做事步骤——先干什么、再干什么、遇到什么问题怎么处理、RAG（检索增强生成）引擎——简单说就是『先查文档再回答』，AI 根据你上传的资料来回答问题，而不是瞎编、Agent 框架、数百模型接入、Prompt IDE |
| 定价 | 开源免费（自部署）+ 云端付费版 |
| Github Star | 77K+ |
| 目标用户 | 开发者、技术团队 |

> [!tip] 关键词：开源、工作流、模型自由
> - ==工作流编辑器==：拖拽式搭 AI 流程，像画流程图一样定义 AI 行为
> - ==模型无关==：可以连接 ChatGPT、Claude、文心一言等各种 AI 大脑，想用哪个随时切换
> - ==RAG 引擎==：上传文档→自动构建知识库问答
> - ==社区庞大==：国内 LLM 应用开发的事实标准之一

## n8n

> [!info] 一句话
> ==190K Star 的开源工作流自动化引擎==——400+ 集成连接器，兼具「低代码拖拽」和「代码灵活」，AI Agent 时代的编排枢纽。

| 维度 | 详情 |
|---|---|
| 厂商 | n8n（开源社区 + 公司化运营） |
| 定位 | 工作流自动化平台（Workflow Automation） |
| 核心能力 | 400+ 集成连接器、可视化工作流 + 代码节点、AI Agent 编排、自部署 |
| 定价 | 开源免费（自部署）+ 云版付费 |
| Github Star | 188K+（2026.5） |
| 目标用户 | 技术团队、自动化工程师 |

> [!note] 什么是工作流自动化？
> 举个例子：每当有人在你的网站填了表单 → 自动把信息存到表格 → 自动发一封欢迎邮件 → 自动通知飞书群里的人。这些『当 A 发生，就做 B、C、D』的连锁反应，就是工作流自动化。n8n 就是做这个的。

> [!tip] 关键词：自动化、400+ 连接器、自部署
> - ==既可以拖拽搭流程（不写代码），也可以自己写代码做更复杂的事==：可以拖拽，也可以写代码
> - ==打通一切==：400+ 连接器覆盖几乎所有常见 SaaS 服务
> - ==AI 节点==：内置 AI Agent 节点，可以在自动化流程中加入一个『AI 步骤』——比如自动发邮件之前先让 AI 帮你润色一下内容
> - 和 Dify 的区别：Dify 偏 AI 应用，n8n 偏自动化流程 + AI 嵌入

## FastGPT

> [!info] 一句话
> ==开源知识库问答平台==——专注做「你上传文档，AI 基于文档回答问题」这一件事，做得非常精。

| 维度 | 详情 |
|---|---|
| 厂商 | FastGPT（开源社区） |
| 定位 | 开源知识库问答系统 |
| 核心能力 | 文档解析、把文字转换成一串数字（向量化），让 AI 能判断两段话是不是在说同一件事、QA 拆分、工作流编排、API 开放 |
| 定价 | 开源免费（自部署）+ 云端付费版 |
| 独特优势 | QA 拆分功能——自动从文档中提取问答对，提高准确率 |
| 目标用户 | 想做智能客服/知识库的企业、开发者 |

> [!tip] 关键词：知识库、精准、开源
> - ==专注 RAG==：不像 Dify 什么都做，FastGPT 只深耕知识库问答
> - ==独门绝活：自动从你上传的文档中提取问答对——比如从产品手册中自动总结出『怎么退货？→ 流程是...』这样的问答，提高回答准确率==：自动从文档提取问答对 → 回答更精准
> - 国内企业在用的很多

## RAGFlow

> [!info] 一句话
> ==开源深度文档理解 RAG 引擎==——核心竞争力是「读懂复杂文档」：合同、财报、学术论文中的表格和段落都不在话下。

| 维度 | 详情 |
|---|---|
| 厂商 | RAGFlow（开源社区） |
| 定位 | 开源 RAG 引擎，专注深度文档理解 |
| 核心能力 | 复杂文档解析（表格、段落、嵌套结构）、向量检索（通过数字匹配找到最相关的文档段落）、知识库管理 |
| 定价 | 开源免费（自部署）+ 云端版 |
| 独特优势 | 文档理解能力最强——能看懂合同里的表格和条款关系 |
| 目标用户 | 需要深度文档理解的企业（法务、金融、学术） |

> [!tip] 关键词：文档理解、表格解析、企业级
> - ==DeepDoc 是 RAGFlow 自研的文档理解算法，专门用来读懂合同里嵌套的表格和复杂的段落==：专门处理复杂文档，不只是「把文字切成块」
> - 适用场景：==合同分析、财报解读、论文审阅==
> - 和 FastGPT 的区别：FastGPT 偏「问答产品化」，RAGFlow 偏「文档理解引擎」

## 🎯 五个平台怎么选？

| 你… | 选 |
|---|---|
| 想快速搭一个 AI 应用，不写代码 | **Coze** |
| 想有更大灵活性、可自部署、可编排复杂工作流 | **Dify** |
| 想打通多个 SaaS 服务、做自动化流程 | **n8n** |
| 只想做私有知识库问答 | **FastGPT** |
| 有复杂文档（表格、合同）需要精准理解 | **RAGFlow** |
