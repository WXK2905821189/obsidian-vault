# 🧩 AI 原生 IDE

> [!note]- 零基础读者必读
> **什么是 IDE**：IDE 就是写代码用的软件，类似程序员专用的 Word + 工具箱。**什么是 AI 原生 IDE**：不是在老软件上额外挂一个 AI 插件，而是从一开始就把 AI 当成核心搭档来设计的写代码工具。**这类工具适合谁**：所有人——打开软件、用中文描述需求，AI 帮你写代码。**你大概看到什么**：一个长得像 VS Code 的软件界面，左边是代码，右边有个对话框可以跟 AI 聊天。

## Cursor（Anysphere）

> [!info] 一句话
> ==目前最火的 AI 原生 IDE==——基于 VS Code 深度改造，Agent 模式可自主多文件编辑，Vibe Coder 首选。

| 维度 | 详情 |
|---|---|
| 厂商 | Anysphere |
| 上线 | 2024 年，持续迭代 |
| 运行方式 | 独立桌面 IDE（基于 VS Code 内核） |
| 核心模型 | 支持 GPT-5、Claude Sonnet/Opus、Gemini 等自由切换 |
| 定价 | 免费版 + Pro \$20/月 |
| 核心能力 | Agent 多文件编辑、Composer 一键生成项目、.cursorrules 项目规范 |

> [!tip] 关键词：接地气、灵活、Vibe Coding 标配
> - ==面向 Vibe Coder 最友好==：Tab 补全 + Chat 对话 + Agent 自主干活 三种模式
> - ==模型自由==：想用哪个模型随时切
> - ==.cursorrules==：写一份项目规范，AI 严格遵守

## Windsurf（Codeium → Cognition AI）

> [!info] 一句话
> ==Cascade 流式 Agent 体验最流畅==——AI 像水流一样自然地在代码间流动。Cascade 是 Windsurf 的一个功能，让 AI 像水流一样持续理解你的代码上下文，而不是一问一答的断断续续。2025.7 被 Cognition AI（Devin）收购。

| 维度 | 详情 |
|---|---|
| 厂商 | Codeium → 2025.7 被 Cognition AI 收购 |
| 上线 | 2024 年 |
| 运行方式 | 独立桌面 IDE |
| 核心能力 | Cascade 流式 Agent、多文件编辑、70+ 语言、企业级安全 |
| 定价 | 免费版有慷慨额度 + 付费版 |
| 备注 | 被 Devin 收购后，与 Devin 形成「IDE + Agent」互补 |

> [!tip] 关键词：流畅、Cascade、Devin 生态
> - ==Cascade 体验独特==：不是「你说一句我回一句」，而是持续理解上下文
> - 被收购后在 Devin 生态中定位为「前端交互界面」
> - 业界评价「最流畅的 AI IDE 体验」

## Trae / Trae SOLO（字节跳动）

> [!info] 一句话
> ==字节跳动的 AI 原生 IDE==——国际版 Trae 和国内版 Trae SOLO，中文理解出色，国内可直接用。

| 维度 | 详情 |
|---|---|
| 厂商 | 字节跳动 |
| 上线 | 2025 年初（国际版），2025.11（SOLO 版） |
| 运行方式 | 独立桌面 IDE |
| 核心模型 | 国际版多模型；SOLO 版基于 Doubao-1.5-pro + 自研 Trae-Agent |
| 定价 | ==免费==（国内版 SOLO 免费开放） |
| 核心能力 | 自主编程（Agentic Coding）：你描述想要什么，AI 自己规划步骤、写代码、测试、修改，一条龙全自动、中文注释理解、国内直接登录 |

> [!tip] 关键词：免费、中文友好、字节生态
> - ==SOLO 版核心概念是 Agentic Coding==——描述需求到发布上线全自动
> - ==国内网络直接用==，无需科学上网
> - 正在深度融入豆包/字节 AI 生态
