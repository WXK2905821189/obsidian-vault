# 🌐 前端 / 全栈 AI 生成器

> 你只需要用中文描述你想要什么，或者上传一张截图——AI 就直接帮你生成一个能点能用的网页/应用。不需要装任何软件，不需要写任何代码。面向「我只有想法，完全没有编程基础」的人。

> [!note]- 零基础读者必读
> **什么是『生成器』**：你在网页上打字（比如『帮我做一个红色的登录页面，左边是表单，右边是图片』），AI 几秒钟就给你变出一个真的能用的网页。**需要你会什么**：会打字、会描述自己想要什么就行。**你大概看到什么**：一个网页界面，左边是你打字的地方，右边是实时生成的预览效果。

## v0.dev（Vercel）

> [!info] 一句话
> ==Vercel 出品的前端组件生成器==——输入描述或图片，直接输出 React/Next.js 组件代码，与 Vercel 部署生态无缝衔接。

| 维度 | 详情 |
|---|---|
| 厂商 | Vercel |
| 运行方式 | 网页应用（v0.dev） |
| 核心能力 | 文字/图片→React 组件、实时预览、一键部署到 Vercel |
| 定价 | 免费额度 + 付费 |
| 核心模型 | Vercel AI SDK 驱动 |

> [!tip] 关键词：组件级、Vercel 生态、前端专属
> - 不是生成整个应用，而是 ==生成 UI 组件==（一张卡片、一个表单、一个页面布局）
> - 输出干净可用的 React/Next.js 代码
> - 和 Vercel 部署一条龙：生成→预览→部署

## Bolt.new（StackBlitz）

> [!info] 一句话
> ==浏览器里的全栈开发环境==——一句话生成完整项目，在浏览器里直接跑 Node.js、装依赖、看效果。

| 维度 | 详情 |
|---|---|
| 厂商 | StackBlitz |
| 运行方式 | 网页应用（bolt.new） |
| 核心能力 | 一句话生成全栈项目、浏览器内运行 Node.js、在线安装 npm 包 |
| 定价 | 免费额度 + 付费 |
| 特点 | 后端集成能力强，比纯前端生成器多出「服务器端」能力 |

> [!tip] 关键词：全栈、浏览器里跑后端、快速原型
> - ==不只是前端==：能在浏览器里跑 Express、数据库操作
> - 快速验证想法：从 0 到可运行的全栈应用，几分钟完成

## Lovable

> [!info] 一句话
> ==面向非开发者的全栈应用生成器==——界面美观度在同类中数一数二，适合做产品原型和 MVP。

| 维度 | 详情 |
|---|---|
| 厂商 | Lovable（欧洲团队） |
| 运行方式 | 网页应用 |
| 核心能力 | 文字描述生成全栈应用、UI 美观度高、一键部署 |
| 定价 | 免费额度 + 付费 |
| 特点 | 被评价为「审美最好的 AI 生成器」 |

> [!tip] 关键词：颜值高、非开发者友好、MVP 利器
> - ==做出来的界面好看==：不像其他工具生成的「理工男审美」
> - ==非技术人员用起来最容易==之一
> - 适合：创业团队快速做产品原型、给投资人展示

## Replit Agent（Replit）

> [!info] 一句话
> ==老牌在线 IDE 的 AI 进化版==——在 Replit 云端环境里，AI Agent 帮你写代码、装依赖、部署上线。

| 维度 | 详情 |
|---|---|
| 厂商 | Replit |
| 运行方式 | 网页/桌面（Replit 平台内置） |
| 核心能力 | 云端开发环境 + AI Agent、协作编辑、一键部署 |
| 定价 | 免费版 + Pro $25/月 |
| 特点 | 不需要本地环境，一切在云端完成 |

> [!tip] 关键词：在线开发环境（云 IDE）——不需要在自己电脑上装任何软件，打开浏览器就能编程。零环境配置、协作
> - ==所有东西在云端==：不用装任何软件，浏览器打开就能开发
> - ==自带数据库和部署==：不需要单独配 MySQL、买服务器
