# 🔌 代码补全插件

> 最不打扰你、但又最无处不在的 AI 帮助——你写代码的时候，AI 在旁边默默帮你补全下一行，就像手机输入法的联想词一样自然。

> [!note]- 零基础读者必读
> **什么是代码补全插件**：你写代码的时候，AI 在后台偷偷看你写的前几行，然后猜你接下来要写什么，自动给你补上。就像你用手机打字时输入法自动跳出联想词一样。**需要你会什么**：需要会写代码（因为你要先写一点，AI 才能帮你补完）。**和 AI IDE 有什么区别**：插件是『附加』在现有 IDE 上的轻量工具；AI IDE 是从头设计的全套 AI 环境。**你大概看到什么**：你正常写代码，写到一半时出现灰色半透明的建议文字，按 Tab 键就接受了。

## GitHub Copilot（GitHub / Microsoft）

> [!info] 一句话
> ==AI 代码补全的鼻祖和行业标准==——在你写代码时自动预测和补全，速度快到「几乎是读心术」。2026 年加入 Agent 模式。

| 维度 | 详情 |
|---|---|
| 厂商 | GitHub / Microsoft |
| 上线 | 2022 年（行业先驱） |
| 运行方式 | IDE 插件（VS Code / JetBrains / Neovim 等 40+ IDE） |
| 核心模型 | GPT 系列 + 自研模型 |
| 定价 | 个人 $10/月，企业 $39/人/月 |
| 核心能力 | 行级/块级自动补全、Chat 对话、Agent 模式（2026 新增）、Workspace 全项目理解 |

> [!tip] 关键词：补全鼻祖、行云流水、最广泛
> - ==写代码时几乎不需要主动问==——它在你停下来之前就把下一行补了
> - 2026 年加入 Agent 模式，从「补全助手」向「自主 Agent」进化
> - 和 Cursor/Windsurf 的区别：Copilot 是插件（轻量），Cursor 是 IDE（重度），路径不同

## Copilot vs AI IDE 怎么选？

| 选 Copilot（插件） 如果… | 选 Cursor/Trae（AI IDE）如果… |
|---|---|
| 已有用惯的 IDE 不想换 | 没绑定 IDE，愿意尝试新的 |
| 只想补全，不想让 AI 接管项目 | 想让 AI 深度参与整个开发 |
| 团队统一用 VS Code / JetBrains | 个人项目，追求极致 AI 体验 |
| 预算 $10/月 | 可以接受免费（Trae）或 $20/月（Cursor） |
